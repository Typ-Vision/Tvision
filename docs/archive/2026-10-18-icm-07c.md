## Kapsam

Industrial Camera Properties kayıtlı kamera/kurulum/profil listesini aynı
MeasurementWorkspace üzerinden sunar. Seçim edinim yapmaz; açık Profili bağla /
güncelle komutu güncel revision/acquisition kimliğini reçeteye alır. Timeout
aynı explicit binding içindedir. Profil düzenleme mevcut bağı stale yapar;
yeniden bağlama ilgili source frame/cache'ini geçersiz kılar. Ölçüm kurulumu bağı
ve profil bağı ayrı komutlardır. Kayıtlı offline kaynak düzenlenip kaydedilebilir.

Görüntü al/Run Flow immutable contract ve yerel route kopyasıyla 07b application
worker/provider yolunu kullanır. UI SDK çağırmaz. Viewer kaynak başına actual
raster/ROI ve mevcut actual evidence içindeki profil/exposure/gain/offset'i sunar.
Normal factory native capability vermediğinden gerçek edinim kapalı kalır;
preview ve kaynak seçimi çevrim/PASS/Run Tool sonucu olarak sunulmaz.
