# CAM-PLAN-03 — Kamera uygulama kartları

4 Kasım 2026. Uygulayıcı: Codex.

## Kapsam ve teslim

Kullanıcı Basler pylon C API ile ilerlemeyi seçti ve altı görevin ayrı kartlarını
istedi. Önceki [analiz/plan](2026-11-04-cam-plan-02.md) sıralamayı içeriyordu;
ayrı uygulanabilir kartlar bu görevde oluşturuldu. Başlangıç HEAD `c8b7d4f`, ağaç temiz.

[Kart dizini](../architecture/camera-backend-cards/README.md):

1. [CAM-SDK-01](../architecture/camera-backend-cards/CAM-SDK-01.md): yerel runtime,
   çoklu producer, seçili producer bütünlüğü ve nedenli hata sunumu.
2. [CAM-OECS-01](../architecture/camera-backend-cards/CAM-OECS-01.md): SDK'lı build,
   px/geometri/readback ve yanlış 1×1 kayıt davranışı.
3. [ICM-BAS-01](../architecture/camera-backend-cards/ICM-BAS-01.md): optional C API
   binding, ABI, exact kimlik/node envanteri ve G0.
4. [ICM-BAS-02a](../architecture/camera-backend-cards/ICM-BAS-02a.md): ürün ayarları,
   gerçek readback/atomik kayıt ve rollback.
5. [ICM-BAS-02b](../architecture/camera-backend-cards/ICM-BAS-02b.md): owned edinim,
   preview, software trigger, Stop/recovery ve G1.
6. [ICM-BAS-03](../architecture/camera-backend-cards/ICM-BAS-03.md): ürün H01–H08,
   gerçek 1000 cycle ve G3; G4/mm ve VF-08 kapsam dışı.

Her kart bağımlılık, dar Oku listesi, davranış, dosya/modül sahipliği, negatif ve
fiziksel kabul, mevcut CTest hedefleri, kanıt dizini ve kapsam dışını tanımlar.
Ortak indeks tam Release ON/OFF, UI görselleri, temiz fixture, checkpoint/sonuç ve
tek kart/commit kapanışını taşır. 02a/02b mevcut BAS-02'nin sıralı alt teslimleridir.
Uygulama C++20/Qt/MinGW kalır; C API teknik ABI doğrulamasını atlatmaz.
