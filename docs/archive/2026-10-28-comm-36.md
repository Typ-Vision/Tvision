# COMM-36 — Çoklu hedef ve whole Pose

Tarih: 28 Ekim 2026. Uygulayıcı: Codex.
Durum: temel faz yazılım/görsel kabulü tamam.
Sonraki tek temel kart COMM-37; opsiyonel protokol/robot kartları başlamadı.

## Kapsam ve davranış

`CommunicationTcpEndpoint::setPublicationTargets` aynı Runtime, owner thread ve
DeliveryStore kullanan en çok 16 ayrı TCP server profilini bağlar. Normal MainWindow
Run da etkin Publish Data grupları için bu bağlantıyı kurar. Her profile tek grup;
ilk etkin Publish Data grubu tetik girişidir. İkincil bağlantılara gelen TRIGGER
TRIGGER_SOURCE_DISABLED olur. Load/Editor/restart kendi başına listener veya Run
başlatmaz. UI aynı peer generation metnini endpoint UUID ile ayrı namespace yapar.

Tüm etkin grupların profil/contract/required bağları, required online ve bağımsız
outbox kapasitesi REQUEST_INTENT/edinimden önce doğrulanır. Aynı cycle UUID hedef
başına CYCLE_BEGIN kaydına bağlanır. İlk hedef orijinal requestId'yi, ikincil hedefler
cycle UUID'yi requestId olarak kullanır. Tek Runtime terminal/bundle commit'inden
hedef başına canonical RESULT manifest'i yazılır. Hedefler aynı cycle/resultBundle
kimliğini taşır; request/hash/attempt/retry/ACK durumu ayrıdır. Birinin ACK'i diğerini
bitirmez; dağıtık atomik commit veya exactly-once effect garantisi yoktur.

`RuntimeCoordinator::setDeliveryPending(owner,bool)` endpoint bariyerlerini OR ile
birleştirir; legacy v2 bool bariyeri ayrı kalır. Required offline/pending yeni çevrimi
engeller; optional offline backlog 128'de QUEUE_FULL olur, kayıt silinmez. Kısmi
manifest yazımı recording/recovery bariyerini korur. İlk hedefin commit edilmiş
çıktısını ACK almak, diğer hedefin recording fault'unu veya kaynak completion'ını
silmez. Aynı terminalle retry edinim yapmaz; commit öncesi ACK sonradan READY'yi
kalıcı kapalı bırakmaz. Diagnostics Retry ikincil hedefe de yönlenir.

`PublicationService::evaluate` frozen profil dependency hash'ini de doğrular.
Whole Pose AssignmentEvaluator üzerinden cycle/config, producer revision, mm ve
exact source/target frame UUID/revision kontrolüyle tek SpatialTransform olarak
geçer. Wire/physical mapping record'un tamamını taşır: T_target_source, right-handed
column vectors, translation Float64 mm, quaternion-wxyz. Scalar x/y/z/rx/ry/rz veya
örtük Euler projection eklenmedi. Missing/invalid kaynak identity/zero'ya çevrilmez.

RESULT resultValid seçilen grubun geçerliliğidir; genel karar değildir. Geçerli
Pose/ölçüm + NOT_EVALUATED mümkündür. ERROR/SKIPPED geçerli grup/evaluated karar
üretemez. Codec shape'i doğrular; required field ve köken otoritesi committed
bundle'dır. Eski v2 değişmez.
