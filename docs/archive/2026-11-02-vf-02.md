# VF-02 · Kalıcı istasyon ve kamera eşleşmesi · K1

Uygulayıcı: Codex

## Kapsam ve uygulandı

Başlangıç HEAD `85a0665`; çalışma ağacı temizdi. Tek uygulayıcı, alt ajan yok.
Onaylı [V4 uygulama planı](../architecture/visionflow-v4-uygulama-plani.md) repoya
alındı; yalnız VF-02/K1 uygulandı. VF-03+ başlatılmadı.

Communication → İstasyon ekle ile ad, mantıksal kamera ve test görüntüsü
kaydedilir. Kaynak ayarları / adlandır aynı istasyonu düzenler. Application
StationSourceSetup görüntüyü gerçek OpenCV decode ile doğrular; okunamayan,
bozuk veya 64 MiB üzeri dosya mevcut eşleşmeyi değiştirmez. Kalıcı kamera kimliği
yeniden adlandırmada korunur; farklı yol yeni kaynak revizyonu, aynı kayıt no-op
üretir. Kaybolan dosyada satır kaynak ayarına yönlendirir.

StationFileSource (station/camera/revision/path) makine IdentityCatalogue'a
aittir, reçete seçiminden ayrıdır. İstasyon/kamera anahtarları, ad ve tam kaynak
tek QLockFile + revision CAS + QSaveFile commit ile saklanır; yarım ilk yazım
orphan istasyon bırakmaz, yarım güncelleme önceki geçerli kaydı korur. İlk kaynak
kaydı JSON schemaVersion=2 üretir; eski schemaVersion=1 okunur ve kaynak
eklenmedikçe aynı biçimde kalır. Bozuk katalog sessizce sıfırlanmaz.

Activation/reçete/terminal geçmiş formatı değiştirilmedi. Eski seçimden otomatik
kamera çıkarımı yapılmaz; açık eşleme kullanılır. Yeni satır panelde hemen
görünür; mevcut server/Runtime owner referansları değiştirilmez. Kaydet sonrası
Runtime için yeniden başlatma açıkça gösterilir; o süreçte Run/Auto/Remote Enable
ve reçete seçimi engellenir. Restart çalışma izinlerini açmaz. Save, drain,
Remote Enable, hedef pending ACK ve Editor/Calibration/Runtime bariyerlerini
denetler. Reçete tool UUID'lerine çözümleme VF-04'e, A/B görüntü işleme VF-08'e
aittir; yeni kaynak bu çözümleme olmadan eski reçete dosyasıyla çalıştırılmaz.

Değişen modüller: StationIdentityRegistry domain/persistence, yeni
StationSourceSetup application servisi, CommunicationWorkspace,
CommunicationStationComposition ve CommunicationPanel; CMake ve yeni test.
Kullanım/sözleşme [Communication workspace](../architecture/communication-v4/communication-workspace.md#vf-02--istasyonun-kalıcı-dosya-kaynağı)
belgesindedir. README boyutu için ayrıntılı Variables anlatımı mevcut rehbere
bağlandı; bilgi bağlantıyla korundu. Graph D:/TVision kökünde kullanıldı;
coverage partial/stale yollar kaynak okunarak tamamlandı. Yanlış save çağrı
kenarı kaynakla değerlendirildi; graph tam etki kanıtı sayılmadı.
