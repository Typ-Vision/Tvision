# ICM-OECS-EXP-02 — deneysel Editor ve gerçek raster px ölçümü

21 Ekim 2026. Uygulayıcı: Codex.
Durum: canlı Editor edinimi / kanıtlı replay ve px geliştirme teslimi hazır.
Bağımsız gerçek mm referansı ve deneysel kalibrasyon aday/aktivasyonu açık;
EXP-02’nin fiziksel mm kabulü veya MUI-04 özgün problem kabulü kapanmadı.

## Kapsam ve değişen dosyalar

- `src/application/{IndustrialExecution,ExecutionService}.{hpp,cpp}`: ortak
  yürütmede oturuma özel açık deneysel politika; canlı istek yalnız Editor lease
  ve production admission olmadan açılır. Açık FrameBurstStart profili gerekir.
  C API owned rasteri, gerçek configure/readback, lease ve deadline/Stop korunur.
  Deneysel kare `IndustrialExecutionEvidence` / trusted completion üretmez.
- `src/application/{ImageFileService,AcquisitionService}.{hpp,cpp}`: açık Editor
  politikasıyla işaretli PGM ve JSON replay. Şema, kimlik, profil/readback codec'i,
  profil-ID/revision/ayar uyumu, temiz tam sensör geometri, raster hash ve false
  admission/eşleşme bayrakları denetlenir. Eksik/bozuk kanıt veya piksel değişimi
  reddedilir. Bilinen JSON varken raster işaretinin kaldırılması da kabul edilmez.
  Bu dosyalar imzalı/kurcalanamaz kanıt değildir; kontrollü ürün yollarında köken
  yükseltilmez. İşaretsiz dışarıdan dönüştürülmüş kopya yeni doğrulanmış kanıt olmaz.
- `src/application/EditorSession.{hpp,cpp}`: açık yükleme politikası; acquisition
  kökeni cache scope'a, JSON içeriği source/tool imzasına katılır. Kalibrasyon veya
  dosya/JSON değişimi TargetOnly girdilerini geçersizleştirir.
- `src/app/{MainWindow,MainWindowEditor,MainWindowExecution,CameraManager}.cpp`,
  `MainWindow.hpp`: Editor seçimi reçeteye/INI'ye yazılmaz; restart'ta kapalıdır.
  Politika değişimi kare/sonuçları temizler. Kalıcı, satır kırabilen deneysel uyarı
  ve sonuç etiketi vardır. Profil düzenleyicisinde açık trigger selector seçimi;
  eski Off/özel selector ve değişmeyen profil davranışı korunur.
- `src/app/EditorUsabilitySmoke.cpp`, `main.cpp`: gerçek raster için elle çağrılan
  `--experimental-editor-smoke`; test INI/proje/rapor/görseller build altında.
- `tests/oecs_experimental_test.cpp`: üç applicationType'ta ortak replay,
  TargetOnly, Stop, JSON/kalibrasyon invalidation, Save/reopen/no-op; eksik/bozuk
  profil/readback, hash, bayrak, kimlik, varsayılan/injected/default cached input
  ve Runtime lease negatifleri.
- `tests/oecs_experimental_probe.cpp`: elle `--editor-run`, ortak ExecutionService
  yolunda gerçek kamera. Probe locator sağlar; gerçek C API tekrar enumerate/exact
  open yapar. Bu koşum UI keşif/yerel route seçimi kabulü değildir.
- README ve Editor kullanım rehberi kullanım değişikliği için; EXP planı teknik
  politika için güncellendi. Progress ve arşiv dizini bu kayda bağlandı.

## Sınırlar ve sonraki adım

Deneysel kalibrasyon sihirbazına aday/aktivasyon köken codec'i eklenmedi;
normal bağımsız capture yolu deneysel dosyayı varsayılan olarak reddeder. Gerçek
referans, lens modeli ve bağımsız fiziksel ölçüm kanıtı yokken mm doğruluğu kabul
edilmez. Uyuşmayan/eksik kalibrasyon negatifleri yeni koşuldu; bunlar gerçek mm
başarısı değildir. Özgün MUI-04 görüntü/reçete/ROI eksikliği devam eder; yeni plaka
önceki telecentrik problemi yeniden üretmiş sayılmaz.

Native Unavailable, 8/8 eski kare karşı örneği ve doğrulanmamış cancel/drain
varsayımı korunur. G0/G1/G3/G4, PLC/robot, CUDA ve dağıtım kabulü kapanmaz.
Sonraki geliştirme EXP-03: ortak Runtime/Logs için ayrı deneysel admission,
completion ve kayıt; trusted production terminaliyle karıştırılmayacak.
Bu teslim tek görev commit'idir; push yapılmaz.
