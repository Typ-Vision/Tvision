# COMM-06 — Set Variables registry/DAG/executor

26 Ekim 2026 · Uygulayıcı: Codex.

COMM-06 tamamlandı. Önkoşul COMM-05 (`f8be5c6`) korunur; sonraki tek kart
**COMM-07**. Push yapılmadı. UI editörü ve Runtime production variable context
bu teslimde açılmadı.

## Kapsam ve değişen dosyalar

- `src/domain/AssignmentConfig.hpp/.cpp`: strict config/value/bundle codec;
  UUID/port/revision, bilinmeyen alan, duplicate target ve constant köken
  denetimi. Int64 decimal string olarak korunur. Codec enum şeklini denetler;
  izinli enum kodlarının otoritesi evaluator'ın recipe variable kataloğudur.
- `src/domain/ToolRegistry.cpp`, `ToolGraph.hpp/.cpp`: `set_variables` sürüm 1,
  minimum Editor şeması 7; `AssignmentBundle` typed portu. Kayıtlı row kaynakları
  `assignmentConnections` / `executionConnections` üzerinden açık dependency
  kenarı üretir. Kayıtlı connections alanına gizli variable adı bağı eklenmez.
  Producer/port/registry veya bundle revision/field ve DAG cycle doğrulanır.
  Aynı variable'a bağımsız dallardan yazım reddedilir; dependency ile açıkça
  sıralanan yazım geçerlidir. Target slice belirsiz rakip yazarı gizleyemez.
- `src/application/AssignmentExecution.hpp/.cpp`, `ExecutionService.hpp/.cpp`:
  saf atomik evaluator mevcut yürütme yoluna bağlandı. Bundle cycle/config
  kimliği taşır, acquisition frame'i ve geometrik origin değildir. Çok kaynaklı
  scalar join, geometrik cross-source yasağını kaldırmadan çalışır. Execution
  kimliği `visionflow.execution/31` oldu.
- `src/application/EditorSession.cpp`: aynı dependency kenarları hedef kapsamı,
  geçişli cache ve invalidation'da kullanılır. Assignment toolSignature variable
  kataloğunu da içerir. TargetOnly acquisition/upstream rerun/fallback yapmaz.
  İmzası geçerli immutable upstream bundle mevcut Editor request config kimliği
  için kopyada yeniden belgelenir; önce bundle cycle/field kökeni doğrulanır.
- `src/application/ToolResultCodec.cpp`: typed bundle payload/union/kimlik ve
  roundtrip; `ToolExecutors.cpp` built-in kayıt koruması.
  `ToolCatalog.hpp` aracı UI kartına kadar Toolbox'tan gizler; mevcut görünüm
  korunur. Yeni ekran veya tool property editörü yoktur.
- `tests/assignment_execution_test.cpp`, `CMakeLists.txt`: Qt Network/Core
  ortamında yeni `assignment_execution_contract`; katalog/config, gerçek
  görüntü/Blob → iki Set Variables → bundle consumer, yanlış port/revision,
  cycle/branch, atomik hata, cache/session/TargetOnly, çok kaynak join,
  Int64 ve üç applicationType doğrulaması. Yerel TCP observer'a Run Tool/Flow
  bağlantısı sıfır; yürütme yolu transport servisi çağırmaz.
- Teknik sözleşme `docs/architecture/tool-execution.md`, güncel kaynak haritası,
  kart/plan indeksi, progress ve arşiv dizini güncellendi.
