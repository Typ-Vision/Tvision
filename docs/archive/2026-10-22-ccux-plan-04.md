# CCUX-PLAN-04 — çalışma süresince kamera bağlantısı planı

Uygulayıcı: Codex

22 Ekim 2026. Kullanıcı, program boyunca sürekli bağlantı yerine Editor reçete
aç/çık, Runtime Run/Stop ve kalibrasyon işlem başlangıç/bitiş sınırlarını seçti;
bu davranışa uygun plan istedi. **Yalnız plan/belge değişti, uygulama başlamadı.**

## Teslim

[CCUX-22 planı](../architecture/camera-setup/22-session-lifecycle.md) altı sıralı
kart içerir: 22a ölçüm, 22b application oturum servisi, 22c Editor, 22d Runtime,
22e kalibrasyon/Camera Manager devri, 22f birleşik ve fiziksel kabul.
Ürün hedefi gereksinimlere, teknik ömür contract C2a'ya işlendi.

Kaydet tek başına kapatmaz; çıkış iptali bağlantıyı korur. Kamera yokken Editor
düzenlenebilir. Runtime Load çevrimdışı; Run bütün gerekli kaynaklar hazır
olmadan Running olmaz. Stop idle/Starting/çekim durumlarında da kapatır.
Kalibrasyon listesi bağlantı açmaz; canlı işlem açar ve bitiş/iptal bırakır.
Sabit owner thread, tek lease, generation/drain, immutable snapshot, kısmi çok
kamera hatasında rollback ve kayıt retry ile donanım kapanışının ayrılması
planlandı. Kare başına stream start/stop ilk sürümde korunacak.

çağırıyor; uzun bağlantı hazırlığı asenkronlaştırılmalı. Stop'un kamera drain'i
de beklemesi gerekiyor. CMakeLists içindeki ilgili test adları plana alındı;
çalıştırılacak kartta ctest -N ile yeniden doğrulanacak.
