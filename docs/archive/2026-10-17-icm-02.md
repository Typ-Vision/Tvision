# ICM-02 — offline backend kararı tamamlandı, fiziksel başarı açık

17 Ekim 2026. [Karar ve teknik sınırlar](../architecture/industrial-camera-backend-decision.md).
Seçim: ortak application adapter altında **OECS C API / dinamik x64 DLL**.
Ürün acquisition kodu, UI, şema, hash veya capability kapısı değiştirilmedi.

## Kapsam ve dosyalar

- `tests/industrial-camera-probe/{CMakeLists.txt,main.cpp}`: ana üründen ayrı opt-in
  Release deneyi, resmi yerel SDK header'ları, typed dynamic export çözümü,
  ABI boyutları, enum ve cihaz varsa getter/cleanup kaydı. Stream/grab/setter yok.
- `scripts/probe-industrial-backend.py`: timeout'lu koşum, child PATH, JSON/exit
  kontrolü, negatif testler ve kaynak/header/binary/lisans dosya hash envanteri.
- Karar belgesi, görev kartı/ana planın durum bağlantıları, progress ve arşiv dizini.
- Önceden var olan dirty dosyalar korundu; commit/push ve `config/local.ui.ini`
  değişimi yapılmadı. SDK kaynak/binary'si repoya kopyalanmadı.

## Yeni doğrulama

Komutların yeniden üretimi karar belgesindedir. Kanıt kökü `build/icm/02/`.

| Kontrol | Yeni sonuç / kanıt |
| --- | --- |
| Ayrı MinGW C++20 Release configure/build | exit 0, `configure.log`, `build.log`, `abi/` |
| GenTL export/load | exit 0; 21 export mevcut, `gentl.stdout.json`; remote XML çalışmadı |
| OECS header/DLL ABI başlangıcı | SDK raw 0x03050200, EnumDevices MV_OK, **0 cihaz**; `oecs.stdout.json` |
| Eksik runtime | exit 1, UNAVAILABLE; `missing-runtime.stdout.json` |
| Yanlış API/CTI | exit 1, missing export ERROR; `wrong-api.stdout.json` |

| Ana UI Release build | exit 0, `ui-build.log` |
| Core OFF Release build | exit 0, `core-build.log` |
| UI ilgili CTest | **2/2 geçti**, camera_transport + camera_probe_diagnostics; `ui-tests.log`, `build/reference-ui/icm-02-tests.xml` |
| Core ilgili CTest | **2/2 geçti**, aynı seçim; `core-tests.log`, `build/kmc9-core-off/icm-02-tests.xml` |

İki build no-work başarıdır; ayrı deney gerçekten derlendi. Ana suite tamamı
koşturulmadı. UI değişmediği için yeni görsel kontrol yoktur. Binary sürüm/hash ve
SDK header/lisans hash'leri `binary-versions.json`/`experiment.json`; doğrudan import
envanteri `oecs-objdump.txt`; kaynak durumu `source-state.json`.
Başlangıç belgeleri `python scripts/check-context-docs.py` ile kapanışta kontrol edilir.

## Sınırlamalar ve devam

GenTL discovery ve C API enum ikisi de sıfır cihaz gördü. Gerçek open/close,
XML/node unit, feature/readback, frame ABI, stream/event cleanup ve grab bu
koşumla doğrulanmadı. Header compile/get-version/enum başarısı bütün SDK ABI'sinin
kabulü değildir. Yerel third-party lisansları vendor redistributable iznini
kanıtlamaz; temiz makine/dağıtım/CUDA kabulü yoktur. G0–G4/H01–H08 açık kalır.

ICM-01b kullanıcı reboot ve gerçek cihaz kanıtını bekliyor. Offline karar kartın
izin verdiği koşullu kapanıştır; sonraki bağımsız ürün görevi **ICM-03a**, ardından
03b. Gerçek readback/grab kapıları ilgili 01b/04b/04c görevlerinde açıkça doğrulanır.
