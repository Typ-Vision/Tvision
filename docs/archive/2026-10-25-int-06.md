# INT-06 — Runtime doğrulama ve restart kullanıcı akışı

25 Ekim 2026. Uygulayıcı: Codex.
Dal: `codex/camera-a0-e2-integration`; taban `CameraIntegration@3793198`.

## Kapsam ve davranış

Load → Kaynağı doğrula → Run → Tek çevrim güncel Runtime'a bağlandı.
Load/restore çevrimdışıdır. Doğrulama kayıtlı modelin exact seçimini ve gerekli
kaynakların yeni probe kanıtını application servisinde denetler; worker yalnız
immutable job/backend tutar. Owner accept sonrası gerçek kamera drain beklenir.
Başarı LoadedStopped durumunu korur; Run, snapshot veya sonuç otomatik üretilmez.
Run'ın Starting/ortak kamera hazırlığı ve Stop/drain yolu korunur.

- Runtime aynı MeasurementWorkspace verification sahibini kullanır; Run/begin
  admission application katmanında kalır. UI model adı/sürümü, kaynak hatası,
  iptal/bekleme ve gerçek frame kimliklerini ayrı gösterir.
- Stop ve proje/pencere çıkış girişimi iptal ister; worker ve gerçek kapanış
  tamamlanmadan workspace değiştirilmez. Callback eski workspace'i yaşatır,
  proje/yol/yüklü reçete kimliğini yeniden denetler. Yeni Load deneme hatasını,
  yeni Verify eski iptal banner'ını temizler.
- Ham dosya dalı model/probe istemez. Metrik replay için canlı fiziksel izni
  yenileme kısıtı korunur. Native/OECS admission, experimental kayıt/Logs/CSV ve
  PLC/robot engelleri mevcut yoldadır; eski kalibrasyon sayfası taşınmadı.
- Katalog silinmesi kaynak etiketi yenilemesinde artık exception kaçırmaz;
  kaynak hatası gösterilir, başarısız Load önceki yüklü reçeteyi korur.
- Geometry eksik kalibrasyon hatası resolver nedenini ve mevcut Setup → Calibration
  yönünü korur. Test adapter factory tek kaynakta da aynı edinim doğrulamalarından
  geçer; varsayılan adapter ve industrial provider yolu değişmez.
