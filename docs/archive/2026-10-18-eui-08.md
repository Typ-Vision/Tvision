# EUI-08 — Birleşik Editor yazılım/görsel kabulü

18 Ekim 2026. Uygulayıcı: Codex. Başlangıç: `331eb7a` (EUI-07).

## Kapsam ve değişen dosyalar

EUI-01–07 birlikte yeniden sınandı. Yeni ürün davranışı, algoritma, SDK bağlantısı,
şema veya engine değişikliği yoktur. Blob4 / engine28 / editor1–9 no-op sınırları,
üç applicationType için ortak Editor/Runtime ve gerçek sonuç olmadan karar
göstermeme kuralı korunur.

- `tests/roi_viewer_test.cpp`: dört overlay ailesi, %10/%25/%100/%400 zoom,
  açıklama açık/kapalı ve iki pencere boyutuyla 64 PNG üretir. Mevcut görünürlük,
  ölçek ve gerçek mouse/key gesture kontrolleri korunur.
- `src/app/EditorSmoke.cpp`: gerçek Editor/application kılavuz yolunda 10 ok,
  inward/outward ve 360°/180°/90° için iki boyutta 12 PNG; güncel fit olmaması
  denetlenir. Fixture parametreleri sonraki kalibrasyon/Runtime kontrollerinden
  önce geri yüklenir. Bunlar sayısal fixture kurulumlarıdır; mouse gesture kabulü
  mevcut ROI/Editor giriş olayları testlerinden gelir.
- `tests/plc_socket_test.cpp`: DONE yanıtları requestId ile eşleştirilir. Önceki
  isteğin tekrarı kuyrukta özellikle bırakılır; iptal edilen isteğin SKIPPED,
  resultValid=false, null değer ve NOT_EVALUATED şartları aynen korunur. Eski
  tekrarın önceki kaydedilmiş sonuçla aynı kaldığı da doğrulanır.
- `docs/editor-usage.md`: doğru EXE, normal/ExecutionPolicy alt süreç komutu ve
  kullanıcının beş talebine karşılık gelen kısa tekrar test listesi.
- EUI planı, progress ve arşiv dizini: güncel kabul/devam noktası.

İlk iki tam koşumda `multi_source_terminal_trace` ve `plc_socket_runtime`
`expected server HELLO` zaman aşımı verdi. Yerel tanı aynı terminal ikilisinde
421 kontrolü geçti; tam yerel core da iki socket testi dahil geçti. Bunlar
ayrı ortam koşumlarıdır; ilk başarısız sonuçlar başarıya çevrilmedi.

İlk yerel UI suite, eski `Stop cannot send stale PASS` hatasını yeniden üretti.
Logda ACK journal hatası sırasında `recording` isteğinin DONE tekrarı, ACK
başarısından önce gönderilmişti; test sonraki `cancelled` isteğini denetlerken
yalnız type=DONE ile ilk mesajı alıyordu. Geçerli önceki isteğin tekrarı yeni
isteğin sonucu sanılabiliyordu. Test korelasyonu düzeltildi; önceki DONE
kuyrukta deterministik bırakılarak aynı yanlış eşleştirme koşulu sınandı.
İptal edilmiş isteğin kendi sonucu üzerindeki güvenlik şartları gevşetilmedi.
Bu hata için Runtime/socket ürün kodunda değişiklik gerekmedi.

İlk UI shell hatası `UI synthetic discovery` idi: ayrı artifact dizini seçerken
beklenen `gentl_test_producer.cti` fixture'ı tarafımdan kopyalanmamıştı. Yerel
suite'in shell adımından önce `ui-local/` içine kopyalandı. Derlenen fixture ve
kopyanın SHA-256 değeri aynı:
`1d839422b2ba03f76a58e0e3a6d3f3144e59256f83d08a2202649171fdcfb58d`.
İlk yerel shell koşumunda PLC simülatörü de eksikti (`UI real result and ACK
timeout`); onu ekleyen odaklı koşum Communication adımını geçti, bu kez kardeş
`../deps/code-fixtures/` dizininin eksikliğini gösterdi (`code independent
fixture`). Kaynak smoke dosyalarındaki dış fixture yolları taranıp sekiz kod
fixture dosyası da kopyalandı. Eksiksiz fixture koşumu 1/1 geçti. Bu hatalar
ürün kodu değişikliğiyle giderilmedi. Tekrarlanabilir son komutlar:

```powershell
# README PATH ayarından sonra; yeni, boş artifact dizini kullanılır.
$env:VISIONFLOW_TEST_ARTIFACTS = 'C:/Projects/Tvision/build/eui/08/ui-final'
New-Item -ItemType Directory $env:VISIONFLOW_TEST_ARTIFACTS
New-Item -ItemType Directory build/eui/08/deps/code-fixtures
Copy-Item build/deps/code-fixtures/* build/eui/08/deps/code-fixtures
Copy-Item build/reference-ui/gentl_test_producer.cti,build/reference-ui/visionflow_plc_simulator.exe $env:VISIONFLOW_TEST_ARTIFACTS
ctest --test-dir build/reference-ui --output-on-failure
ctest --test-dir build/kmc9-core-off --output-on-failure
```

Socket içeren son suite'ler localhost erişimli ortamda çalıştırıldı. İlk UI
koşumu test matrisi derlenirken başlamıştı; son tam yerel koşum tamamen son
derleme üzerindedir. Önceki görevlerin test sonuçları yeni koşum diye sunulmaz.

gruplu Toolbox/arama, Workspace sabit/auto/yüzer, uzun ad/menü/eski INI/busy,

ayrı `ui-final/` içindedir. Tam shell Line Fit/Runtime görselleri de
burada üretilir; eksiksiz odaklı shell görselleri `shell-fixtures-complete/`
içindedir.

850×600 sabit 198×179, auto 316×179. EUI-07 alan kazanımı korunur.

sınanır. Widget setter ile kurulan fixture'lar gesture kanıtı diye sunulmaz.
