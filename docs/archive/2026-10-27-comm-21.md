# COMM-21 — Publish Data ve mapping UI

Tarih: 27 Ekim 2026. Durum: yazılım/görsel kabulü tamamlandı.
Uygulayıcı: Codex

## Kapsam

Publish Data Toolbox'ta açıldı. Properties, output group UUID, Set Variables
bundle UUID/revision, katalogdan typed field UUID ve required/optional endpoint
seçimini sunar. Bir tool birden fazla grup, her grup en çok 64 alan kullanır;
mevcut 16 grup sınırı korunur. Grup/alan ekleme-silme, açık Apply/Cancel ve
revision rebind vardır. Kayıt/açılış/no-op UUID bağlarını korur. Açılış eski
revision'ı sessizce güncellemez; açık yenileme komutu yeniden bağlar.

`ProjectService::updatePublication` grup ve tool değişimini aynı aday tanımda
doğrular; başarısız ara durum projeye yazılmaz. Bir başka Publish Data'nın
grupları korunur; referanslı bir grubun silinmesi mevcut domain doğrulamasına
tabidir. Boş disabled draft açılışı şema/publication alanı eklemez.

Communication profilinde ayrı logical field → TCP JSON field tablosu vardır.
Fiziksel mapping machine-local `CommunicationProfiles` QSaveFile yoluna gider;
duplicate logical key map'e dönüştürülmeden, duplicate destination mevcut profil
servisince reddedilir. Aktif Runtime/bağlantı, dış revision ve no-op guard'ları
korunur. Recipe adres/credential/fiziksel mapping içermez.

Tanım preview'ı UUID/revision ve profil mapping'ini çözer; kaynak type/unit/frame/
enum kontrollerini Set Variables UI ile paylaşır. Missing/duplicate mapping,
disabled kaynak ve bozuk revision görünür hatadır. Field picker metadata'yı
gösterir; uzun frame ayrıntısı wrap/tooltip ile erişilir. Preview canlı değer,
PASS/skor/pose üretmez. MainWindow Editor worker'ı application publication
snapshot'ını bağlantı açmadan capture eder; Run Flow/Tool yalnız intent hesaplar.
Normal v3 Runtime UI aktivasyonu ve birleşik transport kabulü COMM-23'tedir;
transport codec bu kartta değiştirilmedi.
