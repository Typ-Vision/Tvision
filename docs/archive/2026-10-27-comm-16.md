# COMM-16 — TCP v3 codec ve framing

Tarih: 27 Ekim 2026. Durum: yazılım kabulü tamamlandı.
Uygulayıcı: Codex

## Kapsam ve dosyalar

- `src/application/CommunicationWireCodec.hpp/.cpp`: ayrı v3 strict zarf/field
  codec; STATUS/TRIGGER/INPUT/ACK ve HELLO/STATUS/ACCEPTED/BUSY/RESULT/ACKED/
  INVALID/ERROR. Unknown/missing alan, sürüm/tip, invalid UTF-8/Unicode,
  duplicate JSON key, Int64/UInt64 overflow ve nonfinite reddi. Scalar ve tek
  record Pose mevcut domain codec'lerini kullanır. Schema validation authority
  oluşturmaz; catalog/session/exact snapshot kontrolü sonraki adaptöründür.
- Aynı modülde bounded LF framer: line 65536 byte, read chunk 65537 byte;
  ilk partial byte'dan 2000 ms monoton deadline; trickle süreyi yenilemez.
  Hata peer reset gerektirir; retry veya socket dinleme uygulanmadı.
- RESULT canonical payload/hash oturumdan bağımsız; request/result/cycle/config/
  input kimlikleri ve terminal/field verisini taşır. Persisted byte replay
  sözleşmesi [wire belgesinde](../architecture/communication/tcp-v3-wire.md).
- `tests/communication_wire_test.cpp`, `tests/fixtures/communication/vf.socket-3.json`
  ve `vf.socket-2.json`: tüm mesaj örnekleri, scalar/null/Pose roundtrip, exact
  64KiB, fragment/coalesced LF, partial deadline ve schema/hash hata matrisi.
  `CMakeLists.txt` yeni UI bağımsız target/CTest kaydı içerir.
- Plan indeksi/kart durumu, güncel progress ve arşiv indeksi güncellendi.
  Mevcut v2 parser/listener ve simulator değişmedi; v3 listener bu kartta yok.
