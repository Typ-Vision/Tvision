# VF-04a · Editor9 tek dosya Runtime provider düzeltmesi

Uygulayıcı: Codex

## Bildirim, neden ve kapsam

Başlangıç HEAD `c033f66`; çalışma ağacı temizdi. Kullanıcı Dashboard preview’da
önce `Station runtime not bound`, yeniden açtıktan sonra
`Whole source-set configuration provider required` gördü. Reçetesinin
görüntü/Blob/piksel işlemleri olduğunu bildirdi. Normal makine kataloğu salt
okunur incelendi: editor schema 9, tek Image File; kalibrasyon/kurulum bağımlılığı
yok. Kullanıcının identity, publication, activation, görüntü veya INI dosyası
ajan tarafından değiştirilmedi. Kullanıcı kaydedip uygulamayı kendisi kapattı;
normal `build/reference-ui/visionflow.exe` yeniden derlendi.

İlk VF-04 testi tek dosyayı eski editor biçimiyle kuruyordu. Modern schema 9 ise
tek dosyada bile whole-source configuration ve operational provider ister.
Station composition bu portları bağlamıyordu. `station_recipe_selection_test
--editor9` ile aynı hata düzeltme öncesinde yeniden üretildi:
`build/vf-04a/reproduce.log`, `reproduce-result.txt` (exit1). Önceki tam suite
başarısı bu eksik senaryonun başarısı sayılmaz.

## Uygulandı

- `CommunicationStationComposition::fileSources`, tek geçerli Image File
  kaynağı ve piksel grafiği için whole-source kümesini oluşturur. Configuration
  provider `configurationOnly=true`, operational provider false olarak Runtime’a
  bağlanır. Schema 9 ve yayımlanmış içerik korunur; schema düşürme yoktur.
- Gerçek kurulum/kalibrasyon isteyen reçetelere boş dependency ile izin verilmez;
  açık provider gereksinimi gösterilir. Native veya fiziksel/mm kabulü eklenmedi.
- Preview, restart beklenirken veya istasyon Runtime bağlanmamışken kullanıcıya
  programı tamamen kapatıp açmasını söyler; genel `Station runtime not bound`
  hatasına düşmez.
- Yeni `station_recipe_selection_editor9_contract`, mevcut testin modern biçimini
  çalıştırır. Direct Runtime testi de aynı file provider’ı kullanır; executable
  snapshot’ın schema9 kaldığı doğrulanır. Dashboard UI kabulü modern yayına
  geçirildi; restart öncesi mesaj ayrıca sınanır.

Değişenler: CMakeLists, CommunicationStationComposition cpp/hpp,
CommunicationWorkspace.hpp, station_recipe_selection_test ve dashboard_station_ui;
workspace sözleşmesi, progress ve bu kapanış. VF-05 başlamadı.

## Devir

Kullanıcı yeni EXE ile aynı kayıtlı yayında sonucu **“Uyumlu oldu”** diye
doğruladı (`build/vf-04a/manual-acceptance.txt`). Yeniden yayımlama veya veri
silme gerekmedi. Bu beyan otomatik test başarısından ayrı kullanıcı kabulüdür.
Bu bounded provider kalibrasyonsuz tek dosya/piksel yoludur. Kurulumlu metrik
ve native kaynaklar gerçek provider/admission gerektirir. Bağımsız TCP A/B
simülatör kabulü VF-08’de, sıradaki plan kartı VF-05’tir. Fiziksel kamera/PLC/
robot, lens/mm ve dağıtım açık kalır. Kullanıcının “bitirelim, limit dolmak üzere” isteğiyle tam OFF başlatılmadan
mevcut kanıtlarla kapanış yapıldı. Tek VF-04a commit’i; push yapılmaz.
Sayaçlara erişilemiyor; kullanım değeri uydurulmadı. Tek uygulayıcı, alt ajan yok.
