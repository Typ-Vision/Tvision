# ICM-04c — stream/buffer ve owned Mono8 frame

Tarih: 17 Ekim 2026. Uygulayıcı: Codex.
Durum: **yazılım/fixture kapsamı tamamlandı; gerçek cihaz grab kabulü açık**.

## Kapsam ve davranış

OECS C API sınırına SetImageNodeNum/StartGrabbing/GetImageBuffer/FreeImageBuffer/
StopGrabbing/ClearImageBuffer export binding'leri eklendi; vendor struct ve pointer
uygulama sonucuna taşınmaz. Native borrowed record, Get öncesinde ayrılan tracking
alanında Free'ye kadar tutulur. Başarılı Destroy bu kaydı da temizler.

`OecsSession::probeFrame` owner worker'da actual PayloadSize/Width/Height/Mono8
okur. Default 4 buffer, 128 MiB advertised pool bütçesi, 1000 ms wait; count 1–64,
byte limiti en fazla 512 MiB, wait 1–30000 ms. Payload çarpımı yerine bölme ile
allocation öncesi taşma/bütçe kontrolü yapılır. Raster en fazla 100 milyon pikseldir.
Gerçek PFNC/size/stride/received bytes, incomplete/overflow/chunk doğrulanır.

`IndustrialFrameProbe::capture` ImageFrame::fromBuffer ile owned copy yapar;
Free bundan sonra çağrılır. Diagnostic frame'de preview/production admission yok;
source/frame/cycle ID üretilmez. Actual hardware frame ID ve 64-bit cihaz tick'i
ayrı evidence'dır. Completion UTC exposure zamanı değildir; clock epoch uydurulmaz.

Start kısmi başarısında da stop/flush denenir. Borrow edilmiş buffer validation veya
copy exception durumunda da iade edilir. Cleanup başarısızsa kopyalanmış kare bile
sonuç olarak dönmez; oturum Faulted olur. Hata sonrası capture otomatik tekrar
başlamaz; açık close/reopen gerekir. Close/destroy owner thread'dedir; stop sonrası
belirsiz borrowed pointer'a tekrar Free çağrısı yapılmaz. Destroy/unload başarısızsa
ICM-04a library pin ve sahiplik kuralı korunur. Reentrant close/feature/probe reddedilir.

## Sınırlamalar ve kalıcı kararlar

Yerel OECS frame ABI'sinde row stride veya ayrı incomplete status alanı yoktur.
Gerçek binding yalnız `nFrameLen == width × height`, lost-packet=0 tight Mono8
kabul eder; padded/truncated/overflow uzunluğunu tahmin etmez. Explicit stride
bulunan ortak sınır padded rows'u destekler; gerçek padding kabulü iddia edilmez.
Unparsed chunk reddedilir; packed/Bayer/renk decode uygulanmadı.

Pool bütçesi actual advertised PayloadSize × node sayısıdır. SDK iç transfer ve
bookkeeping/RSS belleği için hard limit veya gerçek device minimum-node kabulü
değildir; SDK reddi açık hatadır. Wait süresi SDK'ya verilir; start/stop/close veya
vendor sürücü çağrılarının toplam wall-time/cancel garantisi verilmez (04e kapsamı).

ICM-01b, G0–G4/H01–H08 açıktır. Fiziksel feature/readback/stream ABI/pool/cleanup,
reboot/seri/viewer release, lisans/redistributable ve temiz makine dağıtımı açık
kalır. Software trigger tazeliği/eşleştirme, lifecycle/lease/preview ve kalibrasyon/
Editor/Runtime entegrasyonu bu teslim değildir. Capture/production ret kapıları
kaldırılmadı; gerçek sonuç olmadan PASS/skor/pose üretilmez. Kullanıcı ayarı
`config/local.ui.ini` değiştirilmedi; SDK/header/library repoya eklenmedi.
