# CAM-PLAN-02 — Basler USB ve çok markalı SDK/GenTL planı

4 Kasım 2026. Uygulayıcı: Codex.

## Kapsam ve çıktı

Kullanıcı pylon Viewer kurulumu ve Basler USB görüntüsü bildirdi; OECS onarımıyla
birlikte Basler ve gelecek markaların SDK/GenTL yollarının nasıl belirleneceğini
ve devreye alınacağını analiz etmemizi istedi. Başlangıç HEAD `b170f39`, temiz ağaç.

Kalıcı çıktı [kamera backend devreye alma planıdır](../architecture/camera-backend-activation-plan.md).
Mevcut backend kartları USB hedefiyle güncellendi; tarihsel arşiv değiştirilmedi.
Önceki [OECS/px analizi](2026-11-04-cam-analysis-01.md) korunur.

Karar önerisi: ortak GenTL keşfi, Basler için dar pylon C API edinim adaptörü;
MinGW ABI feasibility ICM-BAS-01 kapısıdır. DLL yolu bilinmeyen SDK'ya otomatik
ürün desteği sağlamaz. Header yolu build'e, runtime/CTI yolu makineye aittir;
proje/reçete physical identity/setup/profile taşır.

Sıra: CAM-SDK-01 ortak yerel runtime/çoklu producer/hata izolasyonu →
CAM-OECS-01 SDK'lı yerel build ve px/readback düzeltmesi → ICM-BAS-01 →
ICM-BAS-02a ayarlar → 02b edinim/G1 → 03 ürün/G3. Uygulama başlamadı.
İki markanın aynı Runtime reçetesinde kullanımı mevcut politika nedeniyle ayrı
sonraki kapsam; aynı PC'de keşif ve ayrı oturum kullanımı kabul kapsamındadır.

## Yeni kanıtlar

- Kurulu `ProducerU3V.cti`, `ProducerGEV.cti`, `PylonC_v10.dll`, PylonC.h ve
  ilgili sürümler/hash'ler envantere alındı.
- Süreç GenTL ortamı yalnız Daheng; Machine ortamı OECS+Daheng+Basler.
  PYLON_DEV_DIR Machine'de var, süreçte yok. Kalıcı ortam değiştirilmedi.
- `visionflow_camera_probe.exe --producer <Basler x64 ProducerU3V.cti>
  --timeout 5000 --scan-wait 250`: sandbox içinde exit 0/sıfır cihaz;
  sandbox dışında exit 0/tek cihaz: **Basler / acA1920-40um / 23102780 / U3V**.
  İki koşum da discovery-only; open-check, feature write veya grab yok.
- Kanıt dizinleri `build/icm/camera-plan-02-20261104-202141/` ve
  `build/icm/camera-plan-02-external-20261104-202203/`. Dış koşumda
  `installed-files.json`, `camera-environment.json`, `result.json`,
  `basler-discovery.json` ve stderr var. Süreç tamamlandı; çalışan test bırakılmadı.

Resmî Basler kaynaklarından CTI/C API/dependency ayrımı, USB buffer/BlockID
semantiği, modelin 1920×1200 default ve 1936×1216 full boyutu incelendi.
Bu değerler bugün canlı geometri readback'i değildir. Web kaynakları planda bağlı.

## Kod analizi ve sınırlar

GenTL keşfinin stream/feature tüketicisi olmadığı; default native factory'nin
kapalı olduğu; ayar servisinin OECS'e bağlı olduğu doğrulandı. Tek producer
seçiminin remembered listeyi değiştirmesi, explicit listenin ortam taramasını
bastırması ve global inventory error kapısının diğer markayı engellemesi bulundu.
Bu kapı doğrudan kaldırılmayacak; seçili producer bütünlüğü ve ambiguity korunacak.

Graph list_projects/index_status ile D:/TVision seçildi. search_graph →
trace_path → snippet/kaynak kullanıldı. İlk dar file_pattern sorguları boştu;
geniş isim sorgusuyla semboller bulundu. Graph'ın genTLProducerPaths callee
eşlemesinde ilgisiz append/contains/compare adayları vardı; bu ilişkiler gerçek
çağrı diye kullanılmadı, kaynakla doğrulandı. 15 kanıt yolu coverage kontrolünden
geçti; partial header/CameraManager/başlatıcı satırları doğrudan kaynakla okundu.

Değişen dosyalar: yeni plan ve bu kayıt, backend kart dizini, progress/arşiv indeksi.
Ürün kodu, CMake cache, INI, proje, driver veya SDK kurulumu değiştirilmedi.
Native C API open/readback/grab, MinGW ABI deneyi, build/CTest/görsel veya fiziksel
mm kabulü yapılmadı. SDK dosyaları repoya kopyalanmadı. Kullanım sayaçlarına
erişilemedi; maliyet/token değeri uydurulmadı. Alt ajan ve push yok.

Devam: CAM-SDK-01 uygulama kartının davranış/ownership/kabul ayrıntılarıyla
uygulanması; VF-08 kamera çalışması sonrasına bırakıldı, K2 kullanıcı teyidi korunur.

Belge kabulü: `python scripts/check-context-docs.py` exit 0; 301 belge,
1275 yerel bağlantı, progress 7989 ve başlangıç toplamı 19851 bayt.
`git diff --check` exit 0. Bu belge kabulü ürün/native kamera kabulü değildir.
