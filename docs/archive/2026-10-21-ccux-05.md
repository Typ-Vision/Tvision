# CCUX-05 — Tek/canlı görüntü ve Durdur UI

21 Ekim 2026.

Uygulayıcı: Codex

## Kapsam ve sonuç

[CCUX-05](../architecture/camera-setup/05-preview-ui.md) uygulandı. İstekteki
`05-registration.md` mevcut değildir; görev ID’sinin indeksindeki `05-preview-ui.md`
esas alındı. Hand-eye, yeni backend, kalibrasyon solver’ı ve tamamlanmış
KMC/ICM/EXP işleri kapsam dışı kaldı. Push yapılmadı.

Camera Manager artık CCUX-04 `CameraPreviewSession` üzerinden Tek görüntü,
Canlı görüntü ve Durdur sunar. Tek görüntü bir kareden sonra temiz kapanır;
canlı önizleme tek pending komut ve latest-frame kapasitesi 1 ile sürer.
FPS worker tamamlanmalarından hesaplanır; ilk karede 0.0 gösterilir.
Continuous capability ve sıralı tek kare ayrıdır; deneysel OECS açıkça
FrameBurstStart/UnverifiedNextArrival olarak kalır. Video dosyası kaydı yoktur.

Stop/error/seçim değişimi görünen kareyi hemen temizler. Uyumsuz kontroller
canlıyken kapalıdır; programatik seçim de session’ı durdurur. Cihaz worker’ı
kapanana kadar ortak job/lease tutulur. Sayfa, proje ve pencere çıkışı event
loop üzerinden drain sonrasına ertelenir; kalibrasyon lease’i erken açılamaz.

PGM+JSON yalnız görünen geçerli deneysel kareden yazılır. Dosya seçicinin
nested event loop’u sırasında görünen raster sabit tutulur; edinim sınırlı
session içinde sürer. Stop/kopma/seçim değişimi revision’ı değiştirir; dosya
seçiminden dönüşte kayıt reddedilir. Single cleanup bitmeden kayıt açılmaz.

## Değişen dosyalar

- `src/app/CameraManager.hpp/.cpp`: application session bağlantısı, komutlar,
  FPS/tür, drain continuation ve görünür kare kayıt kontrolü. Testlerde kullanılan
  deneysel API ve dosya-yolu seçici enjeksiyonları; varsayılanlar gerçek application
  API’si ve QFileDialog’dur. UI donanım SDK’sını doğrudan çağırmaz.
- `src/app/MainWindow.cpp`, `MainWindowWorkspace.cpp`: sayfa/proje/kapanış drain kapısı.
- `src/app/MainWindowCamera.cpp`: pending kamera işinden kalibrasyona geçiş smoke kontrolü.
- `tests/camera_manager_test.cpp`: UI kabulü ve önceki kayıt/ayar regresyonları.
- `tests/OecsExperimentalFixture.hpp`, `oecs_experimental_test.cpp`: mevcut
  sentetik C API fixture’i ortak başlığa taşındı; servis test gövdesi korunur.
- `docs/camera-runtime-usage.md`, progress ve arşiv dizini: kullanım/devam bilgisi.

geçişi shell testinde Runtime hatasından önce geçti.

Görsel kontrol: `experimental-live-1400.png`, `experimental-live-850.png`,
`live-0-1400.png`, `live-0-850.png` ve diğer `camera-*.png` dosyaları.
1400×900 ve 850×600’de görüntü, durum/FPS, Durdur ve kayıt erişimi incelendi;
küçük ekranda dikey kaydırma var, yatay sayfa taşması yok. Görseller sentetiktir;
FPS fiziksel kamera performansı değildir. Test INI/fixture/rasterler build altındadır.

## Açık sınırlar

Ek `ui_shell_smoke`, temiz dizinde de `retry same terminal after Stop` beklentisinde
başarısızdır. HEAD’de de bulunan `MainWindowRuntime.cpp` Stop sonrası retry’de
`runtimeResult_.reset()` yaparken, yine HEAD’de bulunan `EditorSmoke.cpp` aynı
adımda `runtimeResult_` dolu olmasını bekler. Bu iki değişmemiş kaynaktaki beklenti
uyumsuzluğu saptandı; bütün suite PASS iddiası yoktur. Runtime davranışı veya bu
eski smoke beklentisi bu kartta değiştirilmedi; ayrı değerlendirme gerekir.

Fiziksel kamera canlı video/USB kopma/optik/mm doğruluk, native DPI/çok monitör,
CUDA ve dağıtım kabulü yapılmadı. Native backend Unavailable ve OECS pending-command
engeli korunur. Deneysel sonuçlar production admission, PLC veya robot izni değildir.
