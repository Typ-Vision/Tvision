# EFR-03b — ROI crop checkbox, bağlantılar ve gerçek raster

Tarih: 29 Ekim 2026. Uygulayıcı: Codex.

## Teslim

Tek ROI aracının Properties bölümüne reçetede saklanan, busy sırasında kapalı
`cropImage` checkbox'ı ve açık/kapalı kullanım açıklamaları eklendi. Çizim ve
tutamaç düzenlemesi mevcut crop tercihini korur; bağlantılar mod geçişinde
yeniden bağlanmaz. Görüntü kaynağı seçicisi ROI/Image'i açıkça adlandırır.
Region seçicisinin açıklaması parent Region ile child Image'in doğrudan
karıştırılamayacağını anlatır; gerçek execution ret kapısı korunur.

Güncel ROI kapalıyken input + ROI, açıkken gerçek child raster gösterilir.
Giriş görüntüsünde çiz/düzenle eylemi parent rasterı seçer. Bütün Image
tüketicilerinin Editor viewer'ı ve piksel sorgusu bağlı Image girdisini kullanır;
güncel Image çıktısı varsa onu gösterir. Sunum kimliği local coordinate ID
içerir; aynı boyutta başka konuma taşınma eski tutamaç/overlay'i taşımaz.
Image yoksa açık eksik durum gösterilir. Çizim/mod edit'i eski ROI/downstream
sonucunu güncel saymaz; upstream güncel cache korunabilir. Stop downstream
cache'i ve sonuç sunumunu temizler; eski crop Image öğretimde kullanılamaz.

Metrologi drawing/sayısal hazır kapısı actual Image girdisi ve busy durumuyla
yenilenir; koordinatlar child'ın local frame'inde kaydedilir. Kalibrasyon
değişiminden sonra güncel kaynak çıktısı edinmeden öğretim yapılmaz. Circle
fixture'ı yeni kalibrasyondan sonra gerçekten kaynak edinir. Reference/pose
invalidated tombstone'u Properties'de yeniden öğretim uyarısıyla görünürdür.
Match algoritması ve theta çıktısı değiştirilmedi; gerçek sonuç olmadan
skor, PASS veya pose eklenmedi.

Runtime seçili araçta gerçek output/input ImageFrame'i, tüm araçlar görünümünde
edinim root'unu kullanır. Non-Image portların parent/local scope'u doğrulanır;
source/frame/cycle/root uyuşmazlığı reddedilir. RootOffset farkı points,
regions, lines, scans/guides, mask origin ve code corners'a bir kez uygulanır.
Mm typed sonuçlar da kendi raster overlay kökeniyle gösterilir; ROI parent
Region'ı child raster üstüne yanlış çizilmez. UI algoritma/SDK çağırmaz.

Değişen kaynaklar: src/app/MainWindowEditor.cpp, MainWindowMatching.cpp,
MainWindowExecution.cpp, MainWindowRuntime.cpp, MainWindowTracking.cpp,
ImageViewerRoi.cpp, MetrologyEditor.hpp/.cpp ve EditorSmoke.cpp;
src/application/RuntimeOverlay.cpp; tests/roi_crop_consumers_test.cpp.
UI gereksinimi, project-format, roi-geometry, roi-crop-contract ve EFR planı
davranışla eşlendi; progress/arşiv dizini bu kayda bağlandı. Kullanıcının
README.md değişikliği ve config/local.ui.ini bu commit'e katılmadı.
