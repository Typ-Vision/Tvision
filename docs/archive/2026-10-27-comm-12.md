# COMM-12 — Yerel endpoint, output group ve yayın intent çekirdeği

Tarih: 27 Ekim 2026
Uygulayıcı: Codex
Durum: yazılım kabulü tamamlandı; sonraki tek kart COMM-13. Push yapılmadı.
Önkoşul COMM-11 `343db6a`; COMM-10 `4698b33` üzerinden devam edildi.

## Uygulanan kapsam

- `domain/PublicationConfig.*`: explicit recipe publication schema1; canonical
  UUID/revision, required/optional group, logical alan→variable UUID, Set Variables
  bundle revision ve `vf.fields/1`. En çok 16 group, 1–64 field/group. İki group
  aynı bundle'a bağlanır. Katalog/bundle üreticisi/revision/alan uyuşmazlığı,
  aynı enabled group'un iki Publish aracınca kullanılması ve bilinmeyen alan reddi.
- `application/CommunicationProfiles.*`: machine-local file store portu/strict
  JSON ve QSaveFile; TCP client/server DTO, connection ayarı, enabled, timeout,
  retries, opaque credentialRef ve physical mapping. Profil değişimi revision
  artışı ister. Adres/credentialRef/profil mapping'i recipe veya loga yazılmaz.
- `application/PublicationService.*`: capture saf local-store okuması; frozen
  profil kopyası, profile/dependency SHA-256, revision/enabled/mapping kontrolü.
  evaluate yalnız cycle/config bağlı `PublicationIntent` üretir. Bundle provenance,
  valid false Boolean, type/unit/frame/enum katalog authority'si korunur; paket
  başına 64 KiB typed JSON sınırı metadata ile birlikte denetlenir. Bir group
  hata verirse o çağrı kısmi intent listesi döndürmez; retry intent kimliği sabit.
- `ProjectService::outputGroups/setOutputGroups`: tek draft/edit komutu;
  başarısız edit önceki tanımı korur, açık edit dışındaki eski recipe/no-op Save
  byte/hash davranışı değişmez. Fiziksel profil ayarı recipe'ye girmez.
- `ToolRegistry`, `ToolGraph`, `ToolDefinition`, `ToolExecutors`, `ExecutionService`:
  Publish Data registry/config/DAG/executor; group kaynaklarına sentetik bundle
  bağımlılığı; editor sırası üreticiden önce olsa bile doğru DAG sırası. Intent
  ayrı `CycleResult::publicationIntents` alanındadır; network adapter çağrısı yok.
- `ProductionDependencies`/`MultiSourceDependencies::publication` trusted provider
  portları ve `ProductionSnapshot::publication` frozen copy'si mevcut admission
  yoluna bağlandı. Provider her admission'da `PublicationService::capture` eder;
  profil değişince yeni çevrim admission'ı eski dependency hash ile reddedilir.
  Aktif content kimliği sessiz değişmez; Stop/reload/yeniden doğrulama gerekir.
  Snapshot archive dependency'sine yalnız hash girer. Runtime worker frozen
  context'i kullanır; completion digest intent required/identity/alanlarını bağlar.
- `RuntimeService`, `MultiSourceRuntimeService`, `ProductionRecipeService`,
  `SystemCalibration`: cycle-level publication kaynak branch'ine taşınmaz;
  `EditorSession` Stop, upstream invalidation ve config değişiminde eski intent'i
  temizler. ERROR/CANCELED çevrimde başarılı erken publisher intent'i korunmaz.
- `ToolCatalog` Publish Data'yı COMM-21 UI'sine kadar gizler; profile UI veya
  transport eklenmedi. `CMakeLists.txt`, `publication_test.cpp` ve mevcut
  `tool_creation_test.cpp` yeni hidden-core catalog kuralını doğrular.
  Execution identity **visionflow.execution/34**; eski terminal/wire şemaları aynı.

## COMM-13 için zorunlu kayıt kapısı

Bu kart evaluator/intent çekirdeğidir. Terminal bundle/disk outbox teslimi değildir.
Publication snapshot'lı terminalin eski şemaya düşürülerek intent kaybetmesi,
`ProductionRecipeService::record` ve `MultiSourceRuntimeService::finish` içinde
**Publication terminal bundle codec required (COMM-13)** hatasıyla engellenir.
COMM-13 bu iki geçici kapıyı gerçek immutable bundle/codec kayıt yoluyla
değiştirmelidir. Şema7/9'un exact alan seti bu kartta gevşetilmedi. Adapter fake'ı
veya çalışan transport ürün yoluna eklenmedi; Editor/Load/Run Tool sadece intent
hesaplar, dışarı yazmaz. Kapanan yazılım kapsamı fiziksel PLC/robot kabulü değildir.
