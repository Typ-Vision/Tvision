# EUI-06 — Workspace sabitleme / otomatik gizleme

18 Ekim 2026. Uygulayıcı: Codex.
Kullanıcının sıradaki iki görevi sıralı yap talimatındaki ilk görev.

## Kapsam ve dosyalar

`src/app/WorkspacePanel.hpp` ortak navigasyon için 215 px sabit alan veya 28 px
şerit ayırır. Panel host üzerinde kardeş widget olarak yüzer; hover açılışı 150 ms,
çıkışta kapanma 350 ms. Odak, popup/modal veya basılı fare tuşu kapanmayı tutar.
Şeritten Tab/Space ve tıklama erişimi, Escape ile şeride odak dönüşü vardır.
Pin ikonları Qt çizimidir; font glyph bağımlılığı yoktur. Toolbox ayrı kalır.

`MainWindow.cpp/.hpp`: pin/View menüsü, Reset, yerel `workspace/pinned` tercihi,
dar navigasyon satırları. İlk kullanım ve Reset sabittir. `MainWindowRuntime.cpp`:
operatör modunda şerit ve yüzer panel birlikte kapanır; çıkışta tercih korunur.
`EditorUsabilitySmoke.cpp`: gerçek mouse/key/enter/leave olaylarıyla gecikmeler,
focus/popup/modal, restart, Reset, sayfa geçişleri, immutable recipe/execution ve
viewer ölçüleri kontrol edilir. README kullanım, UI gereksinimi, EUI planı,
progress ve arşiv dizini güncellendi. Makinenin yerel INI dosyası değiştirilmedi.
