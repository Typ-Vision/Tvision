# COMM-13 — Immutable terminal bundle ve kayıt codec

27 Ekim 2026 · Uygulayıcı: Codex

## Kapsam

Terminal schema maksimumu 9'dan 10'a çıktı. Enabled Result veya Publish Data
varsa optional resultBundle schema1 eklenir; baseSchemaVersion özgün 3–9
kanıtını korur. Legacy yollar aynı şemayı ve scalar CSV kolonlarını kullanır.
Bundle cycleId/configHash/dependencyId, ayrı genel decision, logical output
group/required/profile contract/intent/dependency ve typed field origin içerir.
Canonical compact bundle içeriğinin SHA256'sı bundleId olur. Secret yoktur.

Missing scalar/Pose null + reason olarak saklanır. SpatialAssignmentValue
codec'i valid transform için eski byte biçimini korur; non-valid spatial
metadata ile null transform kabul eder. Validity ile value çelişkisi reddedilir.
Required invalid grup normal payload/resultValid=true olamaz. Terminal codec
bundle kimlik/hash, recipe group/field/producer ve decision kanıtını doğrular.

ProductionRecipeService::record ve MultiSourceRuntimeService::finish önceki
COMM-12 geçici kapısını kaldırır. Terminal ve bundle aynı ProductionStore
QSaveFile payload'ındadır; ayrı dosya transaction iddiası yoktur. Pending kayıt
aynı ID/bundle içeriğiyle tekrar yazılır; yeni begin/acquisition kapalı kalır.
Restart store okuyucusu tarihsel terminal10'u okur; aktif Run/edinim başlamaz.
Summary bundle kimliği/decision gösterir; CSV base kayıtla aynı scalar çıktıdır.
