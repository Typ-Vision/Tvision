# COMM-20 — Endpoint bağlantı profili UI

Tarih: 27 Ekim 2026. Durum: yazılım/görsel kabulü tamamlandı.
Uygulayıcı: Codex

## Kapsam

Communication ekranına ayrı kaydırılabilir TCP v3 profil sekmesi eklendi.
Makineye yerel depo settings dizinindeki `communication-profiles.json`;
mevcut `CommunicationProfiles` doğrulaması ve QSaveFile atomik kaydı kullanılır.
UUID/revision, Enabled, server/client rolü, IPv4/IPv6 adres, port,
100–60000 ms timeout, 0–10 retry ve maskeli credentialRef düzenlenir.
Credential ref yalnız anahtar adıdır; parola alanı/credential çözümleyici yoktur.
Field mapping korunur, bu kartta düzenlenmez (COMM-21).

Ekle yalnız taslak oluşturur; Vazgeç ve no-op diski/revision'ı değiştirmez.
Yanlış adres, etkin server profilleri arasında adres/port çakışması ve dışarıdan
revision değişikliği görünür hata üretir. Aktif Runtime veya bağlantı denemesi
varken değişiklik reddedilir. Durdurulmuş loaded snapshot değişmez; yeniden
kullanım Stop → Load gerektirir. TCP v2 INI ayarları ve ekranı ayrı sekmede korunur.

`EndpointConnectionProbe` application servisi Qt Network sahibidir. Server
Connect yalnız bind/listen, client Connect asenkron TCP bağlantısı sınar;
server gelen peer'i kapatır, client gelen veriyi atar. Test başarıda bağlantıyı
kapatır; Disconnect timer/socket/listener temizler. Servis Runtime, TriggerRouter,
frame edinimi, RESULT/outbox veya üretim API'sine bağlı değildir. Hata ve status
credentialRef içermez. TLS veya kimlik doğrulaması iddia edilmez.
Normal üretim v3 endpoint aktivasyonu COMM-23'te kalır.
