## Uygulandı

Bağımsız standart kitaplık Python V4 istemcisine `--stations`, `--station`,
`--trigger`, `--recover`, `--state` ve `--expect-decision` eklendi. Product-export
profilindeki installation HELLO'da doğrulanır. Station/recipe/template katalogları
exact revision ile sayfalanır; gerçek stationKey, aktif revision anahtarları,
activation ve cameraSetRevision kullanılır. STATUS hazır/busy/pending ve aktif
seçimi doğrular. Normal tetik uzak SELECT_RECIPE veya Remote Enable açmaz.

Installation/peer/epoch namespace'inde kalıcı uint64 sayaç ve çözülmemiş request
diske ilk socket yazımından önce fsync/atomic replace ile yazılır. Wrap, bozuk
state, başka namespace ve eşzamanlı state yazarı fail-closed'dur. Timeout/kopma
yeni tetik üretmez; açık kurtarma aynı request/body'yi yeni transport session'ıyla
gönderir. Başka station'ın aynı request numarası ayrı eşlenir. Yerel pending
yalnız exact terminalin selection/result UUID/digest'ini echo eden ACKED sonrası
kapanır. Independent SHA256 codec korunur; katalog reason offset'i W6'ya düzeltildi.

ACCEPTED, terminal ve ACKED ayrı gösterilir. Execution, karar, resultValid,
geçerli number/flag slotları, station/request, camera, revision/activation ve
result/digest JSONL ve terminal çıktısındadır. Number slotları ham signed32 wire
değerleridir; mm/ölçek varsayılmaz. Ölçüm kabulü VF-08'de yapılacaktır.

Normal launcher'a açık `-Vf07Acceptance` test seçeneği eklendi; günlük başlatma
aynı kaldı. Ürün smoke'u mevcut MainWindow/Communication/Composition/Runtime ve
ayrı Python process'iyle çalışır; test fixture server, elle katalog/manifest veya
normal ürüne synthetic producer eklenmedi. BUILD_TESTING kapalı derlemede Python
test tanımları zorunlu değildir; açık acceptance modu bu durumda hata verir.

Dosyalar: scripts/communication_v4_simulator.py, scripts/run-local.ps1;
tests/communication_v4_operator_test.py, communication_v4_product_acceptance.py,
dashboard_station_ui.cpp; src/app/main.cpp; CMakeLists.txt; simülatör kullanım/devir
belgeleri. Üretim C++ codec/ledger/selection sözleşmeleri değiştirilmedi.

## Normal kullanıcı akışında doğrulandı

`ui_station_tcp` başlangıçta boş, göreve özel run dizini kullanır. Normal ürünün
Communication kurulum/istasyon dialogu, editör yayımlama ve Dashboard seçimiyle
**İstasyon 1 / Kamera 1 / Yüzey A** oluşturulur. Reçete Blob→Result gerçek Boolean
found çıktısına bağlanır; dosya kaynağı gerçek PNG'dir. Reçetenin kendi rasteri
siyah, istasyonun kalıcı kamera rasteri beyazdır; beklenen OK böylece istasyon
kaynağından geldiği ayırt edilecek şekilde seçildi. Servis fixture'ı normal ürün
işlemlerinin eksik önkoşulunu doldurmadı.

Panelden yetkili istemci kaydedilip test profili dışa aktarıldı. Dashboard tek
eylemle Auto açtı; Remote Enable kapalı kaldı. Bağımsız CLI katalog keşfi ve tek
tetiğinde beklenen **OK, resultValid=true, DONE, exact ACKED** görüldü.
Ürün kabulü altı senaryodan oluşur: keşif, normal sonuç/ACK, dört bayat seçim
alanı, yanlış digest/result/station ACK, timeout'ta intent korunması ve kopma
sonrası aynı UUID/digest'in kurtarılıp exact ACK'lenmesi. Yalnız iki açık üretim
isteği kullanıldı; kurtarma request3 oluşturmadı. Normal executable restart'ta
aynı Kamera 1/Yüzey A/activation korundu; Run/Auto/Remote kapalıydı.
