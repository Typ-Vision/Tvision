# CCUX-14 — Birleşik kamera/kalibrasyon yazılım ve görsel kabulü

22 Ekim 2026. Uygulayıcı: Codex

Birleşik seçili yazılım ve görsel kabul tamamlandı; fiziksel kabul ayrı açıktır.

## Kapsam ve değişiklikler

Yeni `camera_setup_acceptance` application fixture'ı tek kayıtlı projede şu
zinciri kurar: 1/5 kamera kaydı ve otomatik varsayılanlar → tek/canlı önizleme →
Stop/drain → seçili kamerada plaka ve bilinen ölçü → yeni reçete → kaynak başına
kamera seçimi → Editor Run Flow → Runtime → kalıcı Logs/CSV. Kalibrasyon sırasında
hiç reçete yoktur. İki kamera sayısı × üç applicationType aynı test gövdesinde
çalışır; her build'de altı senaryodur. Beş kaynak aynı stripe rasterinden ayrı
modellerle 10/20/30/40/50 mm hesaplar; bağımsız Raw dalı 819200 px2 kalır.
Bu sayılar sentetik raster/SDK fixture sonuçlarıdır, fiziksel ölçüm değildir.

`scripts/accept-camera-setup.ps1`, README toolchain PATH'iyle iki mevcut Release
cache'ini derler; 43 UI / 33 core-off hedefinin gerçekten kayıtlı olduğunu
denetleyip birleşik seçili kabulü çalıştırır. UI olmayan build'de UI hedefi
beklemez. Fixture producer, localhost simulator ve bağımsız kod okuma rasterleri
kanıt dizinine hazırlanır; test INI/TEMP/görseller `build/` altında tutulur.
Son betik varsayılanı yeniden koşumda `build/ccux/ccux-14/run-<tarih-saat>/`
oluşturur; önceki INI/proje/kanıtla karışmaz. Bu kartın ilk koşumu aşağıdaki
doğrudan `ui/`, `core-off/` dizinlerindedir; son UI tekrarı `ui-final/` kullanır.

Görsel incelemede iki dar UI sorunu düzeltildi: sıfır kameralı Calibration
Overview boş CameraId için varsayılan sorgulamıyor; 850×600 Logs başlıkları kısa
ve okunabilir, tam başlıklar ipuçlarında. İlkine durum regresyonu eklendi.
Genel shell'in eski Stop/retry oracle'ı da güncel sözleşmeye uyarlandı: frozen
çevrim kalıcı kayda girer, Stop sonrası eski sonuç/görüntü UI'a geri dönmez.
Üretim/deneysel admission, solver veya kayıt şeması değiştirilmedi.

| Reçetesiz iki yöntem, tek Kaydet ve kullan | E2E canlı deneysel kalibrasyon; `ui_independent_calibration_wizard`, `calibration_save_use`, plaka/wizard/capture ve iki aktivasyon UI suite'i; gerçek raster, kısmi kayıt, retry, ret ve bağımsız kontrol yokluğu |

| Restart, Save As/import, duplicate fiziksel kamera/ID | E2E'de aynı proje/model/varsayılan kimlikleri korunur; import çakışması reddedilir, restart/taşıma kullanım izni başlatmaz; persistence/migration suite'leri legacy no-op ve açık geçişi ayrıca sınar |

UI exit 8/core-off exit 0 bilgisini değiştirmeden tutar. Son UI tekrarının exit 0
sonucu ayrı JUnit/log'dadır. `acceptance-summary.json` bu raporları hedef adıyla
birleştirir; ilk başarısız raporu 43/43 tek koşum gibi yeniden etiketlemez.

`e2e-initial.log`). Son e2e iki build'in birleşik koşumlarında geçti; ön deneme
`e2e-geometry.log` ve ilk derlemeler de korunur.
