## Teslim

- `RuntimeVariables.*`: cycle-local shared-const context, frozen variable tanımları,
  cycle/config/dependency kimliği ve başlangıçta payload'sız Missing değerler.
  Her worker sonucu ayrı context üretir; önceki cycle/Editor cache'i kullanılmaz.
  DONE'da aynı AssignmentExecutor/Evaluator ile atomik bundle doğrulanır, açık
  DAG sırasındaki sonuçlar birleştirilir. ERROR/Stop context'i unset kalır.
- `ProductionSnapshot::variableDependencyId()` catalog, assignment parametreleri,
  editor dependency grafı ve engine'i bağlar. Mevcut recipe contentId bütün
  definition'ı kapsar. Draft rename/binding edit loaded snapshot'ı değiştirmez.
  Context/bundle configId mevcut executor'ın `CycleResult::configId.toHex()`
  metnidir; snapshot contentId'nin kendisi değiştirilmez.
- CycleResult context'i private completion digest'ine katılır. Unset spatial
  transform uydurulmadan hash'lenir. Execution identity `visionflow.execution/32`.
- RuntimeCoordinator yalnız Running + worker idle + başarılı terminal commit
  sonrasında `variables()` verir. Begin/Load/Run/Stop/ERROR/invalid-stale completion
  sunumu temizler. PersistenceFailure context'i gizler; argümansız retry aynı
  dondurulmuş sonucu yazar, edinim yapmaz.
- Stop'tan sonra gelen henüz kaydı dondurulmamış trusted başarı SKIPPED'a
  bastırılır; sonuçlar/kararlar/context temizlenir. Önceden persistence retry için
  dondurulmuş terminal Stop ile yeniden yazılmaz. Startup generation ve eski
  ticket reddi korunur; restart context/Run yetkisi canlandırmaz.
- Tek-source üretim whitelist'i Set Variables için mevcut trusted worker kabulünü
  kullanır. Whole-set ve ayrı experimental worker da aynı context modelini
  kullanır. Typed bundle cycle verisidir; acquisition frame'i uydurulmaz.
  Mevcut terminal codec'i bundle producer/config/revision/field ve cancellation
  sınırlarını denetler; context için terminal/network alanı veya schema bump yoktur.
  COMM-13, network/terminal bundle genişlemesi ayrı kalır.
