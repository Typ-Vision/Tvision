# ICM-03b — acquisition profile ve geometry revision tamamlandı

17 Ekim 2026. Uygulayıcı: Claude Code. Donanım gerekmedi; industrial capture açılmadı.
[Görev kartı](../architecture/industrial-camera-tasks-foundation.md),
[uygulanan sözleşme özeti](../architecture/industrial-camera-contract-plan.md) (§3 tablo altı).

## Kapsam ve dosyalar

- `src/domain/MeasurementSetupContract.{hpp,cpp}`:
  - `GeometryDescriptor2`: endüstriyel setup'ta offset (sensorRoi), binning, decimation ve
    reverse birlikte açık; ROI = çözünürlük × binning × decimation. Yeni alan yoksa schema 1
    bayt/hash aynı.
  - `AcquisitionSettings1` (pixel format, trigger enabled/selector/source, exposure/gain
    auto+değer, ışık beyanı), `AcquisitionProfile1` (ProfileId, CameraId, SetupId, ad,
    revision, `requested`), `revised` ve `acquisitionId` (= setup `cacheId(requested)`).
  - Applied tarafı `GeometryReadback1`/`AcquisitionReadback1`: özellik başına
    `reported`/`not_applicable`/`unknown`; `descriptor()` unknown'u reddeder.
  - Tek invalidation kuralı `acquisitionChange` (setup/geometry/pixelFormat/acquisition/backend
    satırları; calibration/cache/preparation uyumluluk yüklemleri). `MeasurementSetupDescriptor::revised`,
    `AcquisitionProfile::revised` ve `verifyApplied` bu kuralı kullanır.
  - Contract: `profiles` boş değilse schema 2; profile yalnız endüstriyel kamera + aynı kameranın
    setup'ına bağlanır. Webcam setup'ı schema 2 geometri alamaz; endüstriyel complete setup açık
    kritik geometri ister. Endüstriyel setup'ta webcam capability kontrolleri uygulanmaz.
- `src/application/MeasurementEnvironment.cpp`: commit profile geçişini `revised` ile denetler;
  profile silme reddedilir.
- Testler: `measurement_setup_test` (profile/geometry corpus), `measurement_environment_test`
  (restart, sessiz exposure reddi, rename, revision, silme reddi, bundle taşıma),
  `measurement_setup_migration_test` (MeasurementProjectTransfer Save As profili taşır).
- Belgeler: sözleşme §3 notu, baseline şema satırı, plan/kart durumu, progress, arşiv dizini, bu kayıt.

## Kararlar

- Geometri setup'ındır; profile geometri kopyası taşımaz. Requested = setup geometrisi +
  profile `requested`; applied = readback. İkisi `verifyApplied` ile aynı kuralla karşılaştırılır.
- İlk ürün profili yalnız Mono8 ve manual exposure/gain; readback auto/başka format
  raporlayabilir ve uyumsuzluk olarak reddedilir. Float temsil toleransı ICM-04b'dedir (şimdi tam eşitlik).
- `acquisitionId` ad/ID/revision içermez; backend fingerprint yerel olduğu için yalnız
  preparation satırını etkiler. `not_applicable` düğüm kimlik değeriyle aynı geometriyi verir.
- Readback projeye yazılmaz: Save As/import profili taşır, kullanım izni veya capture açmaz.
- 03a testlerindeki "complete" fakat reverse/decimation belirsiz endüstriyel setup artık
  bilinmeyen kritik geometri sayılır; UI endüstriyel kamera oluşturamadığı için gerçek proje etkilenmez.
