# EFR-01 — Flow sağ tık Remove Tool

Tarih: 28 Ekim 2026. Uygulayıcı: Codex.

## Kapsam ve davranış

Flow menüsüne yukarı/aşağı ve ayırıcıdan sonra **Remove Tool** eklendi.
Properties ve menü `MainWindow::removeEditorTool` komutuna gider. Hedef,
seçili araçtan bağımsız yakalanan ID'dir. Açılışta/çalıştırmada gerçek aktif
reçete kimliği, hedef varlığı ve idle denetlenir. Execution/Teaching/Image işi
ve kamera hazırlığı için bekleyen Run sırasında silme reddedilir. Ek onay yoktur.

Başka araç seçiliyse seçim korunur. Seçili araç silinirse sonraki, yoksa önceki
araç seçilir; tek araç silinince Properties boşalır. Başarılı servis mutasyonundan
sonra eski bağlam üzerinden hedef ve downstream Editor cache/reference kayıtları,
cycle/match/overlay ve silinen hedefin çizim niyeti/geçici raster/ROI geçmişi
temizlenir. Aktif Runtime snapshot'ı değişmez.

`ProjectService::removeTool/setTools` politikası değiştirilmedi: normal bağlantılar
temizlenir; reference ve Variables/Result türetilmiş kaynakları eksik DAG hatasıyla
görünür kalır ve geçerli sonuç üretemez. Output Group'un Set Variables üreticisini
silmek Publication doğrulamasında atomik reddedilir; önce grup bağı çözülmelidir.
UI anlaşılır silme bağlamını ve asıl ret nedenini gösterir. Ret halinde reçete,
dirty, seçim, generation ve bekleyen çizim korunur; doğrulama gevşetilmez.
