## Kapsam ve dosyalar

- CameraLocalConfiguration: remembered + süreç GenTL64 canonical birleşimi,
  producer ekleme/çıkarma/devre dışı bırakma; explicit tanı listeyi değiştirmez.
  Backend başına canonical runtime ve bağımlılık dizinleri yalnız yerel INI'dedir.
  Sıra açık/kayıtlı → vendor ortamı → bilinen konum; çoklu aday seçim ister,
  bozuk kayıt başka SDK'ya sessiz geçmez. Header yolu CMake cache'inde kalır.
- CameraService/MeasurementWorkspace/ScopedActiveCalibration: producer başına
  tamamlanma/hata kökeni; global hata metinleri korunur. Sağlıklı B, bozuk A'dan
  bağımsızdır; seçili producer kısmi/iptal/belirsizse ret. Kaynaksız hata için
  konservatif global kapı, exact kimlik/eksik seri/çift rota denetimleri sürer.
- RuntimeLibrary, GenTLTransport ve mevcut OecsCApi: Windows x64 PE/DLL kontrolü,
  DLL'in kendi dizini + yerel bağımlılık dizinleriyle süreç içi yükleme; başka
  kurulumdan aynı adlı yüklenmiş DLL'de restart hatası. Windows loader'a native
  ayıraç verilir. SDK export kontrolü mevcut bağlayıcıdadır; Basler binding yok.
- CameraManager: çoklu producer kontrolleri, OECS/Basler runtime/dependency kaydı,
  derlenmemiş adaptör bilgisi ve meşgulken değişiklik reddi. Runtime değişikliği
  Stop/close sonrası açılır; bağımlılık değişikliğinde restart yönlendirmesi vardır.
  main yerel config konumunu application/hardware sınırına iletir; UI SDK çağırmaz.
  OecsCameraSettings/ExperimentalOecsAcquisition varsayılanları yerel çözümlemeyi kullanır.
- CMake/tests: mevcut camera_transport içinde runtime/producer/Windows bağımlılık
  fixture'ları; Camera Manager hata/busy ve iki boyut görsel kabulü. camera_probe
  JSON çıktısında producer tamamlanma/hata listesi vardır. Kullanım rehberi güncellendi.
  scripts/run-local.ps1 değiştirilmedi: süreç içi loader yolu çözüyor; global/başlatıcı
  PATH eklemesi gerekmiyor. Proje/recipe/export codec değişmedi.
