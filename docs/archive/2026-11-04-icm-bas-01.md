# ICM-BAS-01 — pylon C bağlantısı ve native G0

4 Kasım 2026 · Uygulayıcı: Codex.
Durum: uygulama ve **Basler acA1920-40um / 23102780 / U3V native G0 geçti**.
[Kart ve kalıcı bağlantı sözleşmesi](../architecture/camera-backend-cards/ICM-BAS-01.md),
[sıra](../architecture/camera-backend-cards/README.md).

## Kapsam

- `src/hardware/PylonSession.hpp/.cpp`, `PylonHeaders.hpp`: optional dinamik C
  export binding; owner-thread init/enumeration/exact open/readback/close/destroy/
  terminate. Tek SDK oturumu serialize edilir. C API return code + hemen alınan
  vendor hata detayı korunur. Cleanup başarısızsa handle/runtime tutulur.
- `src/app/pylon_probe.cpp`: CAM-SDK-01 yerel runtime çözümlemesi ve ortak fiziksel
  lease rezervasyonuyla manuel salt okunur USB probe; JSON + exit üretir.
- `CMakeLists.txt`: `VISIONFLOW_PYLON_INCLUDE_DIR` optional cache yolu;
  SDK'sız unavailable yol. `tests/pylon_test_sdk.cpp`, `pylon_binding_test.cpp`:
  gerçek kurulu header'larla fake C export fixture'ı ve binding/ABI kabulü.
- SDK binary/header repoya eklenmedi; ürün provider, ayar UI'sı, grab/trigger,
  hand-eye/eye-to-hand ve kullanıcı `config/local.ui.ini` dosyası değiştirilmedi.

- ABI: x64 pointer/size_t 8, HRESULT 4, bool 1, enum 4, packing 8;
  `PylonDeviceInfo_t` 708 byte, vendor offset 324, serial offset 452.
  Kurulu header/runtime sürümü **10.1.4.1565**. MinGW header sorunları stdint
  guard'ı ve `_stdcall` → `__stdcall` uyumluluğuyla çözüldü; header değiştirilmedi.

Final kaynak incelemesinde aynı thread'in ikinci oturumunda `std::mutex::try_lock`
yerine `atomic_flag` sahipliği seçildi; mutex'in aynı thread'de yeniden alınmasına
dayanılmaz. İkinci oturum busy/close/reopen testi bunu doğrular. Bu değişiklik
nedeniyle hedefli ON/OFF tekrarlandı; tam suite açılmadı.

Başarısız koşumlar silinmedi: ilk build yanlış eski hedef adı nedeniyle başlamadı;
sonraki header compile hataları `build-on-2.log`'da. QLibrary'nin başka referans
varken false dönen unload sonucu yanlış hata sayılmıştı; düzeltildi. Bozuk-DLL
fixture'ı sistem temp'ine yazılamadığı için ilk iki ek koşumda başarısızdı; build
altına alındı ve final test geçti. Bunlar fiziksel G0 başarısı sayılmadı.

## Fiziksel G0

- `physical-initial.log`: sandbox içinde exact cihaz bulunamadı, exit 1;
  cihaz yokluğu sonucu değildir. `physical-external.log`: sandbox dışında exact
  C API enumerate/open/readback/close **exit 0**. Runtime:
  `C:/Program Files/Basler/pylon/Runtime/x64/PylonC_v10.dll`.
- `physical-viewer-busy.log`: kullanıcı Viewer'da exact kamerayı açık tuttu.
  Create aşaması **exit 1**, `rc=0xc2000001`, vendor detayı
  `Device is exclusively opened by another client.`; başka kameraya bağlanılmadı.
  Viewer'ı otomatik açma aracı erişim izni vermedi; kullanıcı elle açıp kapattı.
- Kullanıcı kamerayı Viewer'da kapattıktan sonra `physical-reopen.log` exit 0.
  `physical-wrong-serial.log`: `23102780-WRONG` exact ret, beklenen exit 1.
  `physical-after-wrong.log`: doğru seriyle tekrar open/readback/close exit 0.
  Kullanılmayan hold seçeneği probe'dan çıkarıldıktan sonraki son EXE de
  `physical-final.log` ile exit 0. Son atomik sahiplik düzeltmesinden sonra
  `physical-owner-final.log` da exit 0. Viewer busy/yanlış seri kanıtındaki native
  enumerate/create/open/readback/cleanup çağrıları değişmedi; yalnız süreç içi
  oturum sahipliği değişti ve bu fark son fixture koşumunda sınandı.
- Firmware: `106909-12;U;acA1920_40u;V1.2-1;0`; aktif **1920×1200**, offset
  **8/8**, sensör **1936×1216**, Mono8. Width/Height maksimumu mevcut offset
  bağlamında **1928/1208**, increment **4/1**; sensör boyutu yerine geçirilmez.
  ExposureTime **3000 us [34–10000000]**, Gain **0 dB [0–36]**, auto Off.
  TriggerSelector FrameStart, TriggerMode Off, TriggerSource Line1 okundu.
  FrameStart/FrameBurstStart seçenekleri ayrıdır; hiçbir node yazılmadı.
  Ready/counter/recovery node varlığı/erişimi tam JSON'dadır; destek/iptal/drain
  garantisi veya G1 korelasyonu çıkarılmadı.

Üretici kaynakları: [C API rehberi](https://docs.baslerweb.com/pylonapi/c/programmingguide),
[exclusive open ve C arayüzü](https://docs.baslerweb.com/pylonapi/c/group__pylon).
SDK paket sürümü dosya sürümlerinden türetilmedi; dağıtım/lisans uygunluğu ilan edilmedi.
