## Kapsam ve dosyalar

- `src/application/ToolCatalog.hpp`: Set Variables Toolbox hesaplama grubunda açık.
- `src/app/SetVariablesEditor.hpp/.cpp`: Properties'de 64 satır sınırı, ekle/sil/
  yukarı/aşağı taşı, klavye seçimi; UUID'ye bağlı recipe hedefleri ve type/unit
  uyumlu açık tool output veya upstream bundle field seçimi. System hedefi yok.
  px/px² sayısal portlar unitless/mm alanına sessiz yükseltilmez. Enum/frame
  metadata eşleşmesi ve producer revision korunur; stale kaynak açıkça görünür.
  Typed constant için strict JSON literal girişi domain codec'ine gider;
  Int64 decimal string, String tırnaklı metin, Enum izinli kod, SpatialTransform
  mevcut strict nesne formatını kullanır. Expression/script değerlendirmesi yok.
- `MainWindowEditor.cpp`: taslak tek `ProjectService::updateTool` komutuyla
  atomik uygulanır. Uygula/Save/tool geçişi/Run Tool mevcut Properties commit
  yolunu kullanır; duplicate/unknown/empty/type/unit/revision hatası önceki kaydı
  korur ve inline açıklamayla görünür. Geri al taslağı kayıttan kurar. No-op
  commit revision/dirty üretmez; gerçek edit bundle revision'ını artırır.
  Sonuç etiketi yalnız güncel kabul edilmiş Editor cycle'ından gelir; taslak edit
  veya invalidation önceki Valid sonucunu göstermez. Atomik grup Valid ise bütün
  satırlar geçerlidir; seçili satırda target/source type/unit görülebilir.
- `tests/editor_assignment_ui.cpp`, `MainWindow.hpp`, `main.cpp`, CMake:
  `ui_assignment_editor` / `--assignments-smoke`. Gerçek beyaz image_file → Blob
  count/found portları ve String constant ile üç satır Save→reopen→Run Flow;
  satır taşıma sonrası aynı değerler, invalid/duplicate/empty/type reddi, no-op,
  cancel, disabled state, klavye, kaydırma ve güncel/Missing sonuç etiketi.
  Gerçek `runTool` partial preview yolundadır; Runtime başlatmaz.
- `tests/assignment_execution_test.cpp`: önceki COMM-08'e kadar gizli Toolbox
  beklentisi yeni açık durumla güncellendi. Mevcut gerçek localhost testi Editor
  hesaplamasının ağ çıktısı üretmediğini denetlemeye devam eder.
- README kullanım rehberi, kart/plan/source-map, progress ve arşiv dizini güncellendi.
  Domain/yürütme/persistence şeması veya execution kimliği değişmedi.
