# COMM-18 — V3 restart, dedup ve explicit recovery

Tarih: 27 Ekim 2026. Durum: yazılım kabulü tamamlandı.
Uygulayıcı: Codex

## Kapsam ve dosyalar

- `src/application/DeliveryStore.hpp/.cpp`: `recovery()` bütün kalıcı stable
  request key/fingerprint'lerini journal sequence/hash/transition ve terminal
  manifest doğrulamasından geçirir. `recoveryTerminal()` intent/begin'in cycle
  kimliği için tek terminal10 + bundle arar; belirsiz veya bozuk kanıtı reddeder.
- `src/application/CommunicationTcpEndpoint.hpp/.cpp`: explicit listen sırasında
  namespace'e ait pending/ACK durumunu yeniden kurar; constructor/Load Run veya
  edinim başlatmaz. Terminali olmayan intent/begin RECOVERY_REQUIRED tutar.
  Pending delivery coordinator bariyerini korur. Yeni session ile duplicate
  INPUT/Run olmadan persisted canonical payload/resultId/hash'i replay eder;
  farklı fingerprint REQUEST_CONFLICT olur. ACK tombstone'ları diskte kalır,
  idempotent ACK yeniden ACKED verir ve yeni cycle üretmez.
- `inspectRecovery()` salt okunur application servis komutu;
  `resumeDelivery(exactTriggerRequest)` açık owner-thread reconciliation komutu.
  Terminal commit edilmiş/outbox eksikse cycle, recipe/config ve communication
  request/sequence/input/endpoint/peer kimliklerini doğrulayıp yalnız frozen
  terminal/bundle'dan canonical payload'ı commit eder. Peer bağlı değilken de
  çalışır. Terminal yoksa veya request unknown/foreign/conflicting ise sentetik
  terminal/ACK üretmez. Durable ACK_RECEIVED açık komutla ACK_COMMITTED'a
  ilerler; ACK olmadan receipt uydurulmaz. ACK başka unresolved request'in
  bariyerini açmaz. Recovery busy execution sırasında reddedilir.
- `tests/delivery_recovery_test.cpp` ve CMake/CTest kaydı: child process altı
  kalıcı sınırda gerçekten kill edilir; yeni Runtime/coordinator/router/endpoint
  ile restart testi yapılır. Intent, begin, terminal/outbox gap, pending,
  ACK_RECEIVED ve ACK_COMMITTED; stable dedup, exact wire replay, fresh session,
  unknown/conflict, offline explicit resume, unrelated recovery barrier ve v2
  history isolation kapsanır. Fixture ERROR/NOT_EVALUATED'dır; gerçek parça
  başarısı veya fiziksel kabul iddiası oluşturmaz.
- Plan/kart, source-map, plc-socket sözleşmesi, progress ve arşiv indeksi güncellendi.
  README kullanıcı/build davranışı değişmedi; UI değiştirilmedi.
