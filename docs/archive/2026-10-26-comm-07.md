# COMM-07 — Variable Catalog UI

26 Ekim 2026 · Uygulayıcı: Codex.

COMM-07 tamamlandı. Önkoşul COMM-06 (`ef4111d`) korunur. Sonraki tek kart
**COMM-08**; bu teslim Set Variables çok satırlı tool editörünü açmaz. Push yok.

## Kapsam ve dosyalar

- `src/app/MainWindowVariables.cpp`, `MainWindow.hpp`, `MainWindowEditor.cpp`:
  ortak Recipe Editor Variables sekmesinde ad, tip, scope, birim, değer,
  validity/reason, source, erişim, cycle ID ve açıklama tablosu. Add/edit/remove
  yalnız ProjectService komutlarına gider. UUID readonly; Save/Cancel diyalogu
  enum tanım/kod ve opsiyonel SpatialTransform frame kısıtını da doğrular.
  Referanslı silme/tip/birim değişimi atomik reddedilir ve hata görünür kalır.
  System.RecipeID/CycleID/Decision satırları readonly; sahte genel karar yoktur.
- `MainWindowExecution.cpp`: session reconcile ardından katalog yenilenir.
  Yalnız geçerli Editor presentation ve aynı cycle'ın committed bundle alanları
  DAG sırasında okunur. Boolean false korunur; eksik/eski sonuç yerine sıfır,
  false veya identity üretilmez. Katalog editinde sonuç invalidation vardır;
  current değer tanıma kaydedilmez. Pending Properties kendi tool'una uygulanır.
- Katalog seçiliyken tab minimum alanı 280 px olur; diğer sekmeler mevcut
  compact minimumu kullanır. Table overflow iki yönde scroll ve klavye destekler;
  uzun ad sütunu metne göre büyür, tam metin tooltip'te de bulunur. Hata alanı
  ve modal form scroll'u 850×600'de görünürdür.
- `tests/editor_variable_catalog.cpp`, `src/app/main.cpp`, `CMakeLists.txt`:
  bağımsız `ui_variable_catalog` / `--variables-smoke` kabulü eklendi.
  `tests/editor_property_commits.cpp` içerik olarak değişmedi; mevcut Properties
  regresyonu `ui_editor_usability` içinde çalıştı.
- README kullanım girişi, kart/plan/source-map, progress ve arşiv dizini güncellendi.
  Domain/evaluator/DAG/transport ve şema sürümleri değişmedi.
