# CCUX-16 — normal komutlardan otomatik edinim politikası

22 Ekim 2026. Uygulayıcı: Codex.

## Kapsam ve sonuç

İstekteki `16-physical-acceptance.md` yoktur. Plan indeksindeki gerçek
[CCUX-16](../architecture/camera-setup/16-automatic-acquisition.md) kartı uygulandı;
CCUX-15 fiziksel kabulü bu yazılım kartına taşınmadı. Hand-eye kapsam dışı, push yok.

Application `AcquisitionPolicy` exact Opto/OECS kimliğini ve işaretli PGM/JSON
kaynağını seçer. Politika izin değildir: mevcut loader, gerçek probe, profil,
geometri, raster hash, lease ve Stop/drain kontrolleri korunur. Kamera önizleme,
kalibrasyon, Editor görüntü/Run Flow ve Runtime Load/Run artık ayrı kullanıcı
opt-in seçimi gerektirmez. Diğer dosya/webcam kaynakları OECS yoluna zorlanmaz.
Eksik SDK/yanlış kimlik/rota belirsizliği somut hata olarak kalır.

- Eski FrameStart profili otomatik Burst profiline çevrilmez. Yalnız desteklenen
  kameranın ilk pending profil kaydına FrameBurstStart/Software varsayılanı verilir;
  gerçek edinim configure/readback denetimini yine yapar. Pending optik kurulum
  preview başlatamaz; ayar okuma/kaydı bu denetimden bağımsız kalır.
- Kalibrasyonda permission kabul edilmiş exact canlı probe'dan doğar. Restart,
  disconnect, revision, permission epoch ve A→B→A sınırları korunur. Hatırlanan
  matematik normal yeniden hazırlama komutuyla yeni probe sonrasında kullanılabilir.
- Editor kaynak değişimi/sidecar hash'i mevcut cache imzasına bağlıdır. Explicit
  trusted servis sınırı deneysel pikseli reddetmeye devam eder.
- Runtime yalnız required source graph'tan seçim yapar. OECS/replay + sıradan
  Raw dosya bileşimi test edildi. OECS ile native kamera/webcam bileşimi açık
  hazırlık hatasıdır. Load görüntü/üretim başlatmaz; manuel tetik sınırı Load'da
  uygulanır. Provider değişimi eski hazırlanmış snapshot'ı geçersizleştirir.
- Typed köken, immutable model/snapshot, ayrı experimental codec, false
  productionAdmission/triggerAssociationVerified, persistence retry ve PLC/robot
  blokları korunur. Normal kaynaklar production kabulüne yükseltilmedi.

## Yeni doğrulama ve kanıt

Kanıt kökü: `build/ccux/ccux-16/`. Toolchain ana README'deki PATH ile kullanıldı.
İki CMake cache Release'tir. Bu oturumdaki kontroller aşağıdadır; tarihsel fiziksel
ve CCUX-14 koşumları yeniden çalıştırılmış sayılmaz.

- Core Release build: `build-core-final.log`, exit 0. Kartın 10 CTest'i ve değişen
  ayar yollarının `camera_settings`, `oecs_camera_settings` testleri: **12/12**,
  `ctest-core-accepted.log`, exit 0. Seçim `test-list-core.txt` içinde (ilk 11;
  son gruba oecs_camera_settings eklendi).
- Ana UI Release ve ilgili hedefler: `build-ui-final.log`, `build-ui-fix.log`,
  `build-ui-unchecked-runtime.log`, exit 0. UI testleri: kamera, kalibrasyon
  sihirbazı, çok kaynaklı Editor ve Runtime; ayrıca metric fixture. İlk koşumdaki
  wizard/Editor başarıları `ctest-ui.log` içinde; kamera/Runtime düzeltme koşumu
  `ctest-ui-accepted.log` içinde. Son kutusuz Runtime koşumu
  `ctest-ui-unchecked-runtime.log` içindedir. Bunlar tam UI suite değildir.
- İlk core testinde sandbox localhost HELLO zaman aşımı vardı. Aynı localhost
  testi sandbox dışında çalıştırıldı; eski opt-in negatif beklentileri yeni
  kaynak politikasına uyarlandı. Son 12 test localhost erişimiyle geçti.
- Normal/küçük kamera görselleri: `ui/camera/experimental-live-1400.png`,
  `experimental-live-850.png`; Runtime: `ui/ccux13/runtime-1400.png`,
  `runtime-850.png`. Yeni karelerin ekran dışı görsel kontrolü yapıldı; küçük
  pencere dikey scroll ile çalışır. Rasterlar fixture'dır; fiziksel kamera değildir.
- `python scripts/check-context-docs.py`: `context-docs.log`. `git diff --check`:
  `diff-check.log`. Dosya/kanıt özetleri `verification.json` içindedir.

## Sınırlamalar ve sonraki görev

Görünür eski kutu/uyarılar CCUX-17 kapsamındadır; bu kartta gizlenmedi. Eski
kalibrasyon gezinmesi CCUX-18, birleşik kullanım rehberi/kabul CCUX-19'dadır.

**Fiziksel kabul tamamlanmadı.** Yeni donanım, plaka/mm, lens/odak/düzlem,
bağımsız referans/tolerans veya kullanıcı işlem kabulü koşumu yapılmadı.
CCUX-15c'nin 48 aday/yanlış 49 grid engeli, kopma stop temizleme ve 7000 µs/1 dB
readback reddi korunur. Native OECS Unavailable/pending-command engeli, G0–G4,
PLC/robot ve kurulum/CUDA/dağıtım kabulü açık kalır. Fixture başarıları bunları kapatmaz.

Sonraki görev: **CCUX-17**, sonra kullanıcının sırasıyla 18→19; kalan fiziksel kabul 15.
