# EFR-04 — birleşik ROI kabulü ve tarihsel görüntü sınırı

Tarih: 29 Ekim 2026. Uygulayıcı: Codex.

## Teslim

Üç applicationType aynı saved recipe, Editor Run Flow / Run Tool ve Runtime
senaryosuyla doğrulanır. Yeni editor_flow_roi_acceptance testi iki outer crop
modu, nested child crop ve paralel raw dal kullanır. Gerçek 20×20 nesnenin
area=400, local centroid=(39.5,29.5), raw centroid=(69.5,59.5) oracle'ları
sınanır. Run Tool yalnız hedef aracı güncel child cache'inden çalıştırır;
edinim sayısı sıfırdır. Save/reopen applicationType, parametre ve bağlantıları
korur. Çalışan snapshot'tan sonra taslağın rect/modu değişip kaydedildiğinde
Runtime önceki immutable definition ve crop geometrisiyle sonuç üretir.

Terminal Image geometry ve typed port round-trip root/local coordinate ID,
raw/child boyut, nested rect zinciri, offset/identity ve acquisition
source/frame/cycle/evaluation ilişkisini korur. Child nokta raw'a açıkça
çevrilir; scope'suz child ve offset tamper reddedilir. Eski root envelope
schema 1'e crop scope eklenmez. Restart kaydı birebir okur; active snapshot,
edinim veya yeni sonuç üretmez. Güncel başka cycle rasteri tarihsel overlay
için reddedilir. Genel parça PASS veya robot pose icat edilmez.

Logs ekranına ve ProductionResultCodec ortak özetine **Görüntü mevcut değil**
açıklaması eklendi. Raster arşivlenmediği için geçmiş crop görüntüsü veya
overlay çizilmez. Replay yalnız tarihsel sonuç/köken okumasıdır; görüntü
arşivleme, pikselleri yeniden üretme veya algoritma çalıştırma eklenmedi.
Logs seçimi Stop ile temizlenmiş viewer'ı ve overlay'leri geri getirmez.
UI algoritma/SDK çağırmaz; production izinleri değişmedi.

Tam regresyonun bulduğu Editor bütünleşme boşlukları kapatıldı: geçersiz
piksel/clear bildirimi context üretmez, geçerli pixel sorgusu tek context
kullanır. Aktif çizim aynı content/processing/geometri ve source/frame/cycle
girdisiyle korunur; köken değişirse iptal edilir. Overlay yenilemesi güncel
taslağı setRoi ile sessizce bitirmez. İşlenmiş raster ve bağlı kaynak adı doğru
etiketlenir. Multi-source fixture'ı eski kısa metin yerine gerçek frame/cycle
ve viewer yokluğunu doğrular. Legacy shell fixture'ı zoom için kaynağı açıkça
seçer ve Image input unbind/rebind sonrası modelin canlanmadığını denetleyip
normal UI komutuyla yeniden öğretir. Shell aşama/Editor checkpoint tanıları
sonraki başarısızlıkların hangi kabulde olduğunu görünür kılar.

ROI descriptor'ının sabit Region+Image çıktısına göre output visibility test
beklentisi düzeltildi; iki mod aynı port kataloğunu sunar. ZXing OFF consumer
matrisi Code Read raster kabulünü açıkça unavailable diye bildirir; 12 diğer
Image consumer çalışır. Gerçek QR crop kanıtı yalnız ZXing ON koşumundadır.

Değişen kaynaklar: CMakeLists.txt; src/application/ProductionResultCodec.cpp;
src/app/MainWindowRuntime.cpp, MainWindowEditor.cpp, MainWindowExecution.cpp,
MainWindowMatching.cpp, MultiSourceSmoke.cpp, RuntimeOverlaySmoke.cpp,
EditorSmoke.cpp ve main.cpp;
tests/editor_flow_roi_acceptance_test.cpp, roi_crop_consumers_test.cpp ve
output_visibility_test.cpp. UI gereksinimi, project-format, roi-geometry,
roi-crop-contract, EFR planı, progress ve arşiv dizini bu davranışla eşlendi.
Kullanıcının README.md değişikliği commit'e katılmadı. config/local.ui.ini
test için değiştirilmedi.
