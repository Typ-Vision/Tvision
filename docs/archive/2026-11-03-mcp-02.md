# MCP-02 — Geliştirme araçları araştırması ve Context7 kurulumu

3 Kasım 2026. Uygulayıcı: Claude Code

## Kapsam ve değişiklikler

- Codebase Memory tek yapısal kaynak olarak korundu. Ürün kodu, CMake ve test
  değişmedi.
- **Kuruldu:** kullanıcı düzeyinde `context7` uzak MCP sunucusu
  (`https://mcp.context7.com/mcp`) — Qt 6 ve OpenCV 5.0 sürümüne ait güncel
  doküman. 2 araç: `resolve-library-id`, `query-docs`. API anahtarı gerekmedi;
  OAuth/anahtar yok, config'de sır tutulmaz.
- **Kurulmadı (bilinçli):** Ponytail plugin'i. Her turda kural seti enjekte eder
  ve "en kısa diff" eğilimi bu depodaki zorunlu progress/arşiv/kanıt adımlarıyla
  çakışır. İstenirse plugin değil, talep üzerine yüklenen tek beceri olarak
  eklenebilir.
- **Ertelendi:** clangd/mcp-cpp (LLVM + `compile_commands.json` gerekir; bu
  depoda henüz üretilmiyor), ast-grep (MCP sarmalayıcısı yerine yalnız CLI),
  cppcheck/clang-tidy (script olarak), Windows-MCP (20 araç, sandbox yok,
  kamera uygulamasında yanlış girdi riski). CMake/CTest, GitHub ve
  LSP-retrieval sunucuları mevcut kurulumla örtüştüğü için önerilmedi.

## Doğrulama

- `opencode mcp list`: `codebase-memory-mcp`, `context7`, `filesystem`, `git`,
  `mempalace` — beşi `connected`. Mevcut dört sunucu ve config alanları korundu.
- `query-docs` Qt 6 (`/websites/doc_qt_io_qt-6`): `QThread`/`moveToThread`
  worker örneği kaynak URL'siyle döndü (~8 KB).
- `query-docs` OpenCV (`/websites/opencv`): `minMaxLoc` C++ örneği
  `docs.opencv.org/5.0` kaynağıyla döndü (~12 KB). `/opencv/opencv/5.0.0`
  kimliği Python ağırlıklı sonuç verdi; C++ için `/websites/opencv` tercih
  edilmeli.
- `python scripts/check-context-docs.py` ve `git diff --check` sonuçları
  kapanış commit'inde doğrulandı. Belge-only değişiklik; build/CTest/görsel
  kabul çalıştırılmadı.

## Sınırlamalar ve devam

Context7 eğitim verisi boşluğunu kapatır, çalışan kodu doğrulamaz; Qt/OpenCV
sürüm farkı ve gerçek API davranışı hâlâ derleme ve CTest ile kanıtlanır.
Ücretsiz kota ve ağ bağımlılığı vardır; bağlantı koparsa boş sonuç sayılmaz.

Sonraki isteğe bağlı faz: `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON` ile deneme
build'i alıp clangd MCP'yi üç somut C++ sorusunda Codebase Memory ile
karşılaştırmak; gürültü fazlaysa tek satır config ile geri almak.
