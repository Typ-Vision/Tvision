  Takip dosyaları: progress, arşiv dizini ve bu kayıt.

## Komutlar ve doğrulama

README Qt/MinGW/OpenCV PATH'i ile Release hedef derlemeleri. Donanıma erişim
sandbox dışında, sıralı; başlangıç sandbox keşfi cihaz bulamadı (exit 1), gerçek
cihaz yokluğu olarak yorumlanmadı. Manuel probe request'indeki lens/düzlem
`unidentified/unverified` etiketleridir; gerçek kurulum veya metrik izin değildir.
Origin (0,0); ilk satır kırpılmadı. Raster hash/origin tüm sidecar'larda korunur.

```powershell
# Kanıt kökü $e; DLL $dll; her edinim için yeni mutlak alt dizin.
oecs_camera_settings_test.exe --physical $dll "$e/settings-before.json"
oecs_experimental_probe.exe $dll "$e/preview60" 6000 1 --preview-60s
oecs_experimental_probe.exe $dll "$e/disconnect" 6000 1 --disconnect
# Operatör çıkardıktan sonra (beklenen exit 1):
oecs_experimental_probe.exe $dll "$e/unplugged-open" 6000 1
# Operatör taktıktan sonra run-remaining.ps1: reopen, Stop, Editor 3, Runtime 10.
oecs_camera_settings_test.exe --physical-update $dll "$e/settings-update.json"
# QT_QPA_PLATFORM=offscreen, VISIONFLOW_TEST_ARTIFACTS=$e:
camera_manager_test.exe --physical-settings
# Beklenen exit 1; sonrasında --physical ile settings-final.json:
oecs_experimental_probe.exe $dll "$e/wrong-camera" 6000 1 --wrong-camera
oecs_experimental_probe.exe $dll "$e/wrong-geometry" 6000 1 --wrong-geometry
```

- `build-probe.log` exit 0: 60 s özelliği derlendi ve fiziksel koştu.
  Negatifler eklenirken optional QRect erişimi derlenmedi (`build-probe-final.log`,
  exit 1); düzeltme sonrası `build-probe-negatives.log` exit 0. Ürün UI'sı
  değişmediğinden tüm UI Release yeniden derlenmedi.
  Son Stop başarı koşulları da açık assertion'a bağlandı; her iki manuel hedefin
  son Release derlemesi `build-final.log`, exit 0. Önceki 60 s raporunda aynı
  koşullar yerel audit ile doğrulandı; ikinci 60 s koşumu yapılmadı.
- `build-settings.log`, `build-settings-final.log`, `build-settings-endpoint.log`
  exit 0. İlk scalar harness aynı session'ı ikinci kez kullanarak stale registry
  hatası verdi; `settings-update-stale.log`, exit 1. Reopen sözleşmesiyle düzeltildi.
  Sonraki 7000/1 isteği `settings-update-readback-rejected.log`, exit 1; hata gizlenmedi,
  tolerans gevşetilmedi. Raporlanan gain sınırıyla son `settings-update.log` exit 0.
  Yanlış çalışma dizinli bir shell denemesi executable başlatamadı; fiziksel koşum sayılmaz.
- `run-remaining.ps1` / `remaining-runs.json`: argümanlar, UTC başlangıç/bitiş,
  dört koşumun exit 0'ı. Preview/disconnect/UI/settings başarılı exit 0;

  `test-settings-list.log` / `tests-settings.log` (0.59 s). Eski suite'ler

## Açık maddeler ve devam

Sonraki görev **CCUX-15**: gerçek lens/çalışma düzlemi/ışık/odak, bilinen ölçüyle
aday → deneysel etkin model → Editor mm → Runtime mm → Logs/CSV; plaka hazır
olunca plaka yöntemi; bağımsız referans, belirsizlik ve toleransla bölge/yön
tekrarları. Kullanıcı menü kabulü ayrıca alınır. Plaka yokluğu bilinen ölçü
yöntemini tek başına engellemez; o yol için gerçek kurulum/referans eksiktir.

SDK kopma temizleme hatası ve ara scalar readback reddi açık saha sınırlamalarıdır.
Native Unavailable / pending-command-cancel engeli değişmedi; yeni deneysel
edinimler tetik güveni, production, G1/G3/G4, lens, dağıtım/CUDA veya PLC/robot
kabulü değildir. Özgün MUI-04 raster/reçete/ROI problemi ve Hand-eye kapsamı
bu alt adımla kapanmaz. Push yapılmaz.
