# CCUX-22d — Runtime kamera bağlantı ömrü

Uygulayıcı: Codex

23 Ekim 2026. Runtime Run/Stop ve çok kamera hazırlığı tamamlandı.
CCUX-22e başlatılmadı.

## Kapsam ve dosyalar

`RuntimeCameraSessions.hpp/.cpp` ortak 22b servisini Runtime sahibi olarak kullanır.
Run kaynak/profil/rota/model bağımlılıklarını dondurur, SDK hazırlığı worker'dadır.
`RuntimeService.hpp/.cpp` yalnız bellekte context/generation capability'sini immutable
execution girdilerine bağlar. `RuntimeCoordinator.hpp/.cpp` Starting, generation
kabulü, bütün kümenin rollback'i, kamera drain'ini kapsayan Stopping ve Fault'u
yönetir. Load SDK açmaz; Run tek başına kare veya sonuç üretmez. Tüm kameraların
readback'i ve güncel izin/bağımlılıkları doğrulanmadan Running yoktur.

`IndustrialRuntime.cpp` hazır cihazı context'ten doğrular; her çevrimde yeniden
keşif yapmaz. `MultiSourceRuntimeService.cpp` ve `ExperimentalRuntime.cpp` yalnız
hazırlanmış oturumda uyumlu aynı fiziksel kameranın logical kaynaklarını paylaşır.
Eski oturumsuz çağrıların tekrar cihaz reddi korunur. Gerçek default factory'nin
native admission kapısı açılmadı; test factory'si yalnız bellek içindedir.

Starting/çekim sırasında Stop geç open ve kareyi bastırır, gerçek SDK çıkışına
kadar restart kapalıdır. Kısmi hazırlık veya kamera edinim hatası bütün kümeyi
kapatır. Belirsiz close Fault/lease karantinasıdır. Replug otomatik Run değildir.
Bağımlılık değişiminden sonra Stop tek başına yeni snapshot kabul etmez; açık
Load gerekir. Disk retry kamerayı tutmaz, aynı terminal sonucu yeniden kaydeder.

`MainWindowRuntime.cpp`, `MainWindowEditorCameras.cpp`, workspace/header/constructor
ve `main.cpp` Runtime poll, asenkron durum ve proje/pencere geçiş korumasını bağlar.
Mevcut gezinme/operator kısıtları korunur. `RuntimeCameraSessionsSmoke.cpp` gerçek
UI komutlarını sentetik factory ile yürütür; normal ürün ayarı eklenmez.
`runtime_camera_sessions_test.cpp`, ortak `CameraAcquisitionFixture.hpp`,
`camera_acquisition_sessions_test.cpp`, `MultiSourceSmoke.cpp` ve CMake yeni
kabul fixture'ını ve önceki bekleme kontrollerini günceller. README, kullanım,
ortak sözleşme/plan ve API belgesi güncel davranışı taşır.

Yeni core ve UI matrislerinin her biri 1/5 kamera × üç applicationType × 20 çevrim;
her matriste 120 çevrim, 360 sentetik kamera edinimi. Load 0 open, Run kamera
başına 1 open/configure ve 0 grab; 20 çevrimde ek open/keşif yok, Stop tek close.
Core ayrıca partial rollback, Starting Stop/geç open, in-flight Stop/geç kare,
değişen start/running snapshot ve açık Reload, SDK kopma/manual reRun, close
karantinası, disk retry sonrası drain ve aynı fiziksel kameranın logical kaynak
paylaşımını sınar. OECS fixture'ı 20 karede tek bağlantı ve kare başına stream
start/stop; trusted production evidence oluşmamasını denetler.

UI Starting'de Stop/Run duyarlılığı, sonuçsuz hazır Running, 20 gerçek sentetik
çevrim, idle Stop görüntü emekliliği, geçmiş/CSV ve beş kamera rollback'i denetler.
1400×900 normal ve 1000×700 küçük Qt offscreen görselleri incelendi: temel
komutlar görünür, kaynak tablosu/sonuç ayrıntıları scroll ile erişilir; siyah
3×2 sentetik raster fiziksel görüntü kalitesi kanıtı değildir.
