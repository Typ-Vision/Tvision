## Kabul matrisi

| Sınır | Bu oturumda geçen kanıt |
| --- | --- |
| İki gerçek hesaplama reçetesi | Ölçüm: stripe → edge_point → measurement value/pass → iki variable → Publish Data; kontrol: image → blob count/found → iki variable → Publish Data |
| Birim, OK/NOK ve false | Measurement wire 1 mm, OK ve tolerans dışı NOK/accepted=false; control wire gerçek blob false ile valid NOK |
| NOT_EVALUATED / Stop | Ölçüm/control kabulü Stop sırasında eski OK ve geçerli alanları bastırır; yeni admission kapalı |
| Request/cycle/result/hash | Wire trace ve kalıcı canonical RESULT karşılaştırması; yanlış ACK ve conflict reddi |
| Kayıp ACK / aynı payload retry | delivery_retry_runtime otomatik/manual timeout, reconnect, geç ACK; acquisition tekrarlanmaz; 130 çevrim ve eski tombstone korunur |
| Restart | delivery_recovery_contract: altı ayrı öldürülmüş process sınırı; intent/begin recovery, terminal gap ve ACK uzlaştırma; otomatik Run yok |
| Disk / commit sırası | communication_tcp_runtime: intent/terminal/DELIVERY_PENDING/ACK_COMMITTED hataları; terminal commit öncesi gönderim yok; retry aynı edinim |
| Queue / endpoint offline | delivery_retry_contract: optional 128 QUEUE_FULL, ortak disk bütçesi, required offline; sessiz eviction yok; optional_runtime tek in-flight backlog drain |
| Eksik/stale/invalid/type/unit/frame | trigger_router_contract, publication_contract, assignment/decision/result ve wire sözleşmeleri |
| Farklı cycle bileşenleri | publication_contract: mixed-cycle, revision, eksik required alan ve tip/birim reddi |
| Editor / Run Tool / Load | ui_publication_editor ve ui_tcp_acceptance: observer üzerinde 0 bağlantı; yalnız intent; Load ve unchecked Run endpoint açmaz |
| Selected / draft / loaded | Measurement dirty tolerans active snapshot'ı değiştirmez; UI farklı seçili taslağa rağmen loaded recipe/profile kullanır |
| V2 / framing / close | plc_socket_runtime ve communication_tcp_runtime: v2 alanları korunur, port collision, stale session, partial 2 s ve 64 KiB sınırı |
| Diagnostics / restart izni | UI gerçek endpoint bind/release, kalıcı ACK, Stop/drained close; yeni MainWindow v3 iznini geri yüklemez |
