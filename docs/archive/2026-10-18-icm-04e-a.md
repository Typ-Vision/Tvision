## Kapsam ve değişen dosyalar

- `src/application/CameraWorkerSession.{hpp,cpp}`: existing `CameraLifecycle`
  üzerinde owner-thread controller ve tek kalıcı worker. Backend factory, execute,
  shutdown ve destructor aynı worker'dadır; controller SDK çağrısı beklemez.
- Exact `PhysicalDeviceIdentity` vendor/model/serial anahtarı ile süreç içi exclusive
  lease. Calibration, Editor ve Runtime kullanım amacı/source/producer farkı aynı
  cihaz için ikinci sahip yaratmaz. Yalnız serial veya eksik kimlik kabul edilmez.
- Tek uçuşta komut; owner `poll()` completion teslimi. Production FIFO Full dispatch
  öncesinde reddedilir; preview latest-drop mevcut lifecycle üzerinden korunur.
  Eksik/foreign frame başarı yayımlamaz. Backend exception, deadline/cancel ve
  generation değişimi Fault/late-result bastırma kurallarını korur.
- `requestStop()` derhal generation/cancel ve kuyruk invalidation yapar. Çağrı
  drain olduktan sonra açık `submit(Stop)` acknowledgement veya `requestShutdown()`
  gerekir. Bu API donanım pending-command cancel/bariyeri sağlamaz.
- Worker ömrü session'ın `JobSession::Connection` işiyle izlenir. Nonblocking
  shutdown ve Stop bütçesi aşımı kaynakların serbest kaldığını söylemez. Backend
  cleanup/destruction ve join bitmeden lease bırakılmaz. Cleanup exception'ında
  süreç boyunca lease karantinası + Fault/error korunur. Ready yalnız worker'ın
  bittiğini söyler; başarılı kamera recovery anlamına gelmez.
- `tests/camera_worker_test.cpp`, `CMakeLists.txt`: yeni
  `camera_worker_lease_contract` corpus'u. Mimari sözleşme/görev kartı, progress ve
  arşiv dizini güncellendi; README kullanım davranışı değişmedi.

## Sınırlamalar ve sonraki görev

- Native backend factory, registry/provider ve Calibration/Editor/Runtime ürün
  bağlantısı kurulmadı. OecsSession'ın mevcut backend kilidi kaldırılmadı. Caller
  supplied backend/result trusted Runtime completion sağlamaz.
- Shutdown önce owner polling ile tamamlanmalıdır. Destructor cancel+join yapar;
  kesilemeyen SDK'da bloklanabilir. Force terminate, detach veya erken DLL unload yok.
  Backend shutdown partial/fault halde cleanup yapmalıdır; exception lease'i
  karantinaya alır. Cross-process lease/process isolation sonraki kapsamdır.
- Preview→production native bariyeri, unplug/replug/1000-cycle/teardown stress,
  fiziksel G0–G4/H01–H08, sahne/lens/ölçüm ve dağıtım kabulü yapılmadı.
- **Sonraki native görev ICM-04e**, ICM-04d belgeli pending-command
  cancel/completion/drain/reset kanıtına bağlı. Stop/Start veya Clear tekrarları bu
  engeli kapatmaz. Kullanıcının destek beklemeden ilerleme yönlendirmesi korunur;
  bağımsız sonraki alt görev seçimi native admission açamaz. ICM-05a ürün
  registry/factory kabulünün 04e önkoşulu sürer. Push yapılmaz.
