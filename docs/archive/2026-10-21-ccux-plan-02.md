# CCUX-PLAN-02 — robot dışı uygulama planı ve bağlam sadeleştirme

21 Ekim 2026. Uygulayıcı: Codex

## Kapsam

Kullanıcı kamera/kalibrasyon/reçete sadeleştirmesinin detaylandırılmasını istedi;
Hand-eye/Eye-to-Hand açıkça hariç. GPT-6.1 Sol / medium için
[plan indeksi](../architecture/camera-setup/README.md), ortak sözleşme ve
CCUX-01–15 kartları hazırlandı. Her kart dar okuma, kaynak sembol/dosyaları,
uygulama, negatif kabul, mevcut CTest hedefleri ve teslim sınırı taşır.
Son kart gerçek cihaz/referans/tolerans gerektirir; fixture bunu kapatmaz.

## Kararlar

Kamera ID/varsayılan kayıt → ayar/readback → sade UI → canlı session/UI → model
geçerliliği → deneysel kalibrasyon → kaydet/kullan → sihirbaz → Editor bağları →
reçete alanları → deneysel Runtime mm/Logs → yazılım/fiziksel kabul sırası.
Eski kayıt/no-op, native Unavailable, deneysel oturum onayı ve blocked PLC/robot
korunur. Yeni robot/lens/ChArUco solver veya vendor SDK bu pakette yoktur.
